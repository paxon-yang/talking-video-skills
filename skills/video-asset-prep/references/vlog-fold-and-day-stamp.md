# 技法卡：空间折叠 / AI 转身换景 / 转场 vlog 合集（2026-11-09）

> 来源：三段抖音手机录屏（2026-11-09 入库）。只有录屏，画面里叠着抖音界面，分辨率低，时间是录屏秒数（30fps）。
> 代号：**B** 空间折叠打开升达（560×1280，17.5 s，原片横屏约 12 s，录屏里放了一遍半）；**C** 某 211 学姐 vlog（560×1280，53 s，原片横屏，标注「疑似使用了 AI 生成技术」）；**A** 刷「转场 / odd vlog」信息流的 5 分 32 秒录屏（314×720，22 条不同作者的片子，每条看 10–20 s）。
> 测法：帧差找切点；关键过渡逐帧（30fps）原分辨率抽图目视；位置、时长目视读数，标「约」。
> 三段学的东西不同：**B 学的是一个具体转场的结构**（空间折叠，0.6 s）；**C 学的是「人不动、世界换」的转身换景和日程字幕**；**A 学的是一整个流派的共同语法**（odd vlog / 转场 vlog），以及评论区对它的反应。
> 何时读：片子里要从「真实照片」进入「海报化 / 观点画面」时读第一部分；要做「一天 / 一步一步」的时间线段落时读第二部分；想给口播片加生活感 B-roll 或软广时读第三部分。

# 第一部分　B：空间折叠（真实照片 → 海报世界）

## 0. 一句话

**主体一动不动，世界像卷帘一样换掉。** 真实照片被往下挤走，一张「海报天空」（橙色渐变 + 红日 + 鸟群 + 巨大立体英文字）从顶部卷下来，主体建筑（抠像）始终钉在原位，地面变成带波纹的镜面倒影。整个过程 18 帧（0.6 s），每个地标一次，四个地标轮流（城门 DENGFENG → 思源会馆 SIYUAN GUILD HALL → 图书馆 SHEN… LIBRARY → 亭子 SHUWAN PAVILION），每段约 3 s。

## 1. 逐帧记录（亭子那一次，录屏 11.4 s 起，帧号相对）

| 帧 | 画面 |
|---|---|
| 0–3 | 原照片（蓝天、树、亭子），静止或极慢推 |
| 3–5 | 上下黑边往里挤（约各 8% 高），照片被压扁、整体下移 |
| 5–8 | 顶部出现一条橙色海报带，带鸟群；照片仍在下面，照片里的亭子屋顶已被海报带切过 → 画面上同时有两个亭子（海报上的抠像 + 下方照片里的原图），这个「重影」是故意的，读成「空间被折了一下」 |
| 8–12 | 海报带继续往下卷，下沿到画面中部；一轮红日从照片和黑边之间的缝里升起（从画面底下往上） |
| 12–16 | 海报覆盖到地平线（约 0.80H），照片只剩一条贴地的窄带（约 0.035H 的草地）；巨大英文字 SHUWAN PAVILION 在亭子**后面**模糊淡入 |
| 16–18 | 地平线以下变成镜面倒影（上半画面上下翻转、压暗、水波扭曲），收住 |
| 之后 | 静止约 2 s（鸟群一直在飞），硬切下一个地标的原照片 |

## 2. 规律

### SF1 只换背景，不动主体
- 规则：转场期间主体（建筑抠像）坐标不变；变的是它身后的世界。观众的视线锚在主体上，所以 0.6 s 的大变化也不乱。
- 置信度：高（四次都是这样）。
- 我们怎么用：口播片里「同一个东西，换个视角看」——比如同一张 Claude 截图，从真实界面折成「观点海报」；数字人画面也能当主体（抠像不行就用画中画卡片当主体）。

### SF2 卷帘方向 = 从上往下，带内容一起滑
- 规则：海报不是淡入，而是一条从顶部往下长的带子，带子里的内容（渐变、鸟）跟着下沿一起往下滑约 0.18H，像拉下一张卷帘。照片同时被往下推（不是被裁掉），推动量约为海报下沿位移的一半。
- 数值：挤黑边 0–22% 时长；卷帘 15–75%；红日 30–85%；倒影 55–100%（都按 18 帧的比例，目视）。
- 置信度：中。

### SF3 海报三件套：大圆 + 鸟群 + 主体后面的巨字
- 规则：海报世界只有三样：一个纯色大圆（太阳，半径约 0.17H，位置在主体正后方偏上）、几十只剪影鸟（一直在飞，给静止画面「活气」）、一行巨大立体字（字高约 0.2H，橙黄色 + 两层深色投影做出厚度，压在主体后面、只露出没被挡住的部分）。字被主体挡住一部分反而更像海报。
- 置信度：高。
- 注意：字用英文 / 拼音（笔画规整，被挡一半还认得出）；中文大字被挡后难认。

### SF4 地面变镜面，画面重心上移
- 规则：地平线以下不保留真实地面，换成上半画面的倒影（压暗约 45%、水平条纹扭曲）。效果是把「照片」变成「海报」：上 80% 是设计，下 20% 是倒影底座。
- 置信度：中。

### SF5 节奏：一个地标一次，3 s 一个
- 规则：原照片 → 折叠（0.6 s）→ 海报停约 2 s → 硬切下一张原照片。不在海报上再加别的动画。
- 我们怎么用：适合「盘点 N 个东西」的段落（比如 4 个 AI 工具），每个 3 s，用同一个模板换主体和字。

### 已做成积木
私有积木库 `SpaceFold`（batch 6B）：传 `photo` 和同尺寸的 `subject` 抠像（PNG），`title` 填巨字，`foldAt` / `foldDur` 控时，`horizon` 控地平线。没有素材时显示内置的亭子预览。

# 第二部分　C：AI 转身换景 + 日程字幕

## 0. 一句话

**人不动（脸始终在画面同一个位置），世界在她转身、甩头、头发扫过镜头的一瞬间换掉。** 配合手写体「时间 + 事情」字幕（8:00 化妆 / 8:30 整装完成 / 9:00 去上课 / 12:00 吃饭 / 16:30 买零食 / 17:30 坐公交 / 20:00 赶地铁 / 20:20 到学校 / 20:30 拿快递 / 21:00 家教 / 23:00 剪辑），把一天串成一条 40 s 的线。平台标注「疑似使用了 AI 生成技术」，合集名「转场 vlog」——换景是首尾帧 AI 视频生成补出来的。

## 1. 关键过渡（录屏秒数，原片约从 1 s 开始）

| 时间 | 过渡 | 怎么做的 |
|---|---|---|
| 3.3–4.0 | 便利店 → 宿舍化妆 | 侧脸平移，硬切；切到的第一帧就是满屏毛笔大字「化妆」+ 右上小字「8:00」 |
| 6.5–7.2 | 宿舍 → 林荫道 | 她转身，头发甩过画面（约 6 帧），甩完背景已经是树；中间有 2–3 帧宿舍书架和树林同时存在（AI 补帧的痕迹），脸落在和上一镜相同的位置 |
| 8.8–9.0 | 公交上自拍 → 林荫道 | 叠化 2 帧 + 快推 |
| 9.9–10.1 | 林荫道 → 街上两人走 | 甩镜头（横向运动模糊约 3 帧）硬切 |
| 11.6–12.1 | 街上 → 食堂 | 她扭头，马尾甩过镜头，落地时人在食堂；同时右上角打出「12_」→「12:0_」→「12:00」，3 帧后「吃饭」浮出 |

## 2. 规律

### C1 转身 / 甩头 = 免费的遮挡转场
- 规则：主体自己的动作（转身、甩头发、手挡镜头）遮住画面的那几帧就是切点。脸在前后两镜里落在同一位置（约画面中线、上 1/3），所以眼睛不用重新找。
- 置信度：高。
- 我们怎么用：数字人口播里，数字人转头 / 抬手的那几帧可以作为换背景或换卡片的切点；没有这个动作就用「物体擦过镜头」（R2 已有的遮挡擦除）。

### C2 AI 补帧做「不可能的转场」
- 规则：拍两个真实镜头（首帧、尾帧），用 AI 视频生成补中间 0.3–0.6 s 的变形，人物保持一致、环境变化。痕迹是中间帧两个场景混在一起。观众在评论区会讨论「这个怎么拍的」，平台会打 AI 标。
- 置信度：中（平台标注 + 混合帧推断）。
- 对我们：这正是 AI 知识博主的选题素材——「这种转场怎么做」本身就能出一期；做片时可以用首尾帧生成来给数字人换场景（数字人姿势相同的两帧当首尾帧）。

### C3 日程字幕：时间打字 + 事情浮出
- 规则：右上角两行手写体白字。上行时间逐字打出（约 2 帧一个字符，带下划线光标 `_`），时间打完后约 3 帧，下行事情两字淡入上浮。字不大（时间约 0.07H），不加底色，靠画面本身够亮 / 够暗。
- 置信度：高（逐帧可见 12_ → 12:0_ → 12:00）。
- 我们怎么用：「第一步 / 第二步」、「9:00 打开 Claude / 9:05 跑完测试」这种按时间推进的段落。

### C4 一个段落只给一次大字
- 规则：整条片里只有「化妆」用了满屏毛笔大字（宽约 84% 画面，硬切进、约 4 帧从 1.06 缩到 1、停约 1 s、硬切出），其余全是小号日程字。大字是开场钩子，用多了就成了「一直大字叠底」。
- 置信度：中。
- 我们怎么用：符合我们已有的「不要一直大字叠底」——满屏大字一支片只用 1–2 次，放在最想让人停住的那一拍。

### 已做成积木
`DayStamp`（时间打字 + 事情浮出）、`BrushSlam`（满屏毛笔大字），batch 6B。

## 1. 流派共同语法（A1–A7）

### A1 一个东西贯穿，背景一直换
- 规则：同一个物件（咖啡杯、酒瓶、果汁、音乐卡片、玩偶）在每一镜里位置相近，背景场景一直换。#11 #13 #22 最典型。和 §26「一个东西贯穿到底」一致，是它在实拍里的版本。
- 我们怎么用：口播片里贯穿物可以是「一张 Claude 对话卡」或「一个产品图标」，每次换背景（数字人画面 / 实拍 / 网页）它都还在同一位置。

### A2 系统 UI 当道具，而且是「本片自己的信息」
- 规则：音乐播放卡显示的是本片 BGM；天气 App 显示的是当天天气；地铁屏显示的是真的时刻。UI 半透明、带透视、和天空 / 手机 / 窗台对齐，像真的在那儿。（R1 香港 vlog 的 F1 已有，这次再次确认是整个流派的通用做法。）
- 新增：**UI 可以当贯穿物**（#22 音乐卡一直钉着，背景换）；**整屏 App 界面可以半透明叠在天空上慢慢滚**（#13，透明度约 0.5，颜色接近天空蓝）。
- 我们怎么用：AI 话题片里，把 Claude / ChatGPT 的真实界面、通知、灵动岛当道具放进实景，内容写本片正在讲的那句。

### A3 形状蒙版转场：用画面里的东西当窗口
- 规则：落叶、相框、矩形窗、楼面窗格、手机屏——画面里现成的形状直接成为下一镜的窗口，窗口放大吃满屏完成转场。#5 #8 #12 #19 #22。
- 我们怎么用：口播片里最现成的形状是「手机屏 / 电脑窗口 / 卡片」，用它们当窗口进入下一段（已有 CardMorphBg、ScreenComposite 可用）。

### A4 2D 小贴纸点缀真实画面（odd 风）
- 规则：手绘大眼睛贴在落叶上、问号、星星、手势光标、描红线、彩色描边字，全都很小（约画面 5–10%）、黑白线稿或高饱和单色、出现时 2–3 帧弹出。只点缀，不盖住主体。
- 对比：这和我们否掉的「满屏 3D 金鱼贴纸」不同——它们小、平、少、和真实物件互动（贴在叶子上、指着杯子）。
- 我们怎么用：给数字人 / 实拍加「手绘批注感」：圈一下、画箭头、贴个问号，参考 PenStroke / MarkerLine。

### A5 卡点 = 每拍只改一样东西
- 规则：#3 每拍点亮一块颜色；#7 每拍点亮一个方块；#12 每句歌词换一个镜头。每一拍的变化都很单一，所以快也不乱。

### A6 软广最自然的形态
- 规则：22 条里至少 6 条是软广（玩偶、奶茶、咖啡、果汁、二锅头、茶百道），形态都一样：产品是贯穿物（A1），出现在生活场景里被「用」，不说卖点，标题是情绪句。
- 对我们：豆包等商单可以参考——产品界面当贯穿物，场景跟着 AI 知识点换。

### A7 评论区的提醒：只有技术没有内容
- 证据：#7（纯几何蒙版转场）弹幕 / 评论「这个视频表达了什么吗？只有技术没有内容，怎么会火」「你说简单麻烦我认了，但是哪来的高质量」。
- 规则：观众能分辨「炫技」和「有内容的炫技」。#19（Zoe）同样是纹理转场，但每一镜是一座城市、有地名，就有内容。
- 我们怎么用：所有炫技动效都要挂在一句口播信息上（这张卡在讲什么）；纯技术展示段 ≤ 3 s。

## 2. 和 AI 知识博主人设最相关的三条
