# 规律层：精品动效反复出现的规则

每条写成：**规则 → 数值 → 来源（视频 + 时间）→ 置信度**。
- 视频代号：**A** 求职工具宣传片（77s，1920×1080，29.97fps）；**B** Claude Code / Artifacts 发布片（60s，1280×720，24fps）；**C** Claude 企业版 MCP 连接器片（34s，1920×1080，24fps，动画本身多为 12fps）；**D** 19 分钟抖音录屏（60 多条 AI 产品广告合集，代理 1280×722@30，时间是录屏秒数）。原始拆解在 `<工程目录>/analysis/ae-study/`，校准在 `out/motionlab/batch*/VERIFY.md`。
- 置信度：**高** = 像素实测且经独立复测或多片印证；**中** = 单片实测，或多片目视一致；**低** = 拼图目视读数（±10–30%）或只有一处证据。
- 两处材料互相矛盾时，以后做的独立实测为准，矛盾处单独标出。帧数一律写明是哪个 fps 的帧（见第 13 节教训）。

## 1. 无限画布 + 虚拟相机，转场靠运镜不靠切镜
- 规则：所有窗口、卡片、标题都摆在同一张世界画布上，镜头在它们之间推、拉、摇；背景是画布的一部分。下一屏的背景往往就是上一屏的某个物体（对勾圆 → 卡片 → 页面）。
- 数值：推近 `cubic-bezier(0.25,0,0.15,1)`，约 1.15s（B 0.12–1.27s，拟合 rmse 0.006）；焦点拉回 `cubic-bezier(0.45,0.1,0.35,1)`，0.9s（A 48.10–49.0s，22 个宽度样本拟合；卡片原写 (0.3,0,0.2,1)/0.85s，在 +0.3s 处快约 12%）；镜头平移指数减速，130 → 20 px/帧@30，用时 0.5s（D 49–60s howone，目视读数）。
- 来源：B 卡 0（背景与前景同帧位移完全一致、静止段帧间 SAD=0）；C 通用规律 1；A 通用规律 8。
- 置信度：架构 **高**（三片独立得出）；曲线数值 **高**（A/B 拟合）；D 平移 **低**。
- 落地：一个镜头只用一个相机（scene.camera / WorldCamera / PushIn / ScrollCamera 四选一，lint 会拦）。停留段加 2% 左右的线性微推，免得画面死住（C 28.3–31.3s BETA 标题定格加 2% 漂移，中；A 通用规律 7 写的是「每 0.1s +0.3–1%」，未复测，低）。

## 2. 缓动：几乎全是指数衰减（ease-out，无过冲），分两档
> 2026-10-20 补：这是「长尾」族（宣传片 / 镜头）的规律；交互 UI 演示类素材系统性地用弹簧过冲，两者是风格选项，见第 19 节 X2。
- 规则：入场 = 每帧剩余距离乘一个常数 k（`remaining = k^(t·30)`），不用弹簧过冲。中间移动用 ease-in-out bezier。
- 数值与何时用：

| 档 | k（每 1/30s 剩余） | 到 88% | 用在 | 来源 | 置信度 |
|---|---|---|---|---|---|
| calm | 0.84（= 每 1/15s ×0.7） | 约 12 帧 | 大面板、整屏、镜头尺度的入场 | A 5.05–5.78s 面板升起；batch2X 重测 0.713/(1/15s) | 高 |
| snappy | 0.65–0.70（代码用 0.68） | 约 6 帧 | 小元素：emoji、图标、卫星、网格单元、芯片 | B 通用规律；D 846–852s emoji 独立重测 0.633 | 高 |
| 介于两者 | 0.775 / 0.81 / 0.87 | 8–15 帧 | 锁屏机身上升 / 线框立方体放大 / 竖排词行距收拢 | B 36.14s；D 138.55s；D 1123.4s | 中（均为拟合） |
- 其它实测：网格单元 0.5 → 1 倍，每 1/24s ×0.58（≈每 1/30s ×0.647，C 4.2–12s，像素实测，高）；圆形裁切前 3 帧 ×0.82–0.88 再近线性（D 150.87s，中）。
- 无过冲的证据：A、B、C 全片未见 spring 过冲（三片通用规律）；D「BOUNCE」emoji 实测无弹跳（W3 卡 10）。例外只有两处小回弹：像素吉祥物落地（B 7.72s）、圆点滑块弹簧（D 947.7s）。
- 换算：24fps 素材的 k 要换到 30fps：`k30 = k24^(24/30)`。代码里秒制参数与 fps 无关，优先用秒。
- 矛盾标注：BLOCKS v1 曾写「入场每帧剩 0.7」；A 实测是每 1/15s 剩 0.7（= 每帧 0.84），0.65–0.7/帧是 B/D 的值。已更正，两档并存。

## 3. 界面状态 0 帧硬切，只有镜头和入场有缓动
- 规则：按钮换态、面板开合、标签替换、z 序切换都在 1 帧内完成；动的是镜头和元素入场。这是「像真的在操作软件」的来源。
- 数值：大转场 = 0 帧硬切 + 前后 1–3 帧的缩放/模糊/遮罩（D W1 全组）；点击后「硬切 + 2 帧空场 + 面板指数升起」（A 4.9–5.78s）；换态用「按下 0.91 → 下一帧硬切 → 回弹」，不做 morph（B 45.44–45.77s）。
- 来源：B 卡 0 与通用规律 2；D W1 附注 5；A 通用规律 3（几乎不用交叉淡化）。
- 置信度：**高**。

## 5. 爆发式打字：分段变速 + 词边停顿
- 数值：B 首条 96 字用 1.75s，平均 57 字/s；匀速段约 50–60 字/s，burst 段 80–130 字/s，词/短语边界停 0.15–0.7s（B 0.33–2.08s，逐帧计数，高）。A 标题左→右蒙版显现 60–64 字/s（A 0.4s 起，高）。链接高亮窗约 9 字宽、44 字/s（B 37.4–38.5s，中）。光球领字是线性 13 字/s（D 144.4s，低）。D 合集各片在 57–300 字/s 之间分段变速（低）。
- 规则：正文不染色，只有链接/标题这类标记段先染强调色、0.25s 衰减回基色（B 30.5–32.65s；我们最初默认全染是错的，已改）。B 打字无光标。
- 置信度：B/A **高**，其余 **低**。

## 8. 后期克制：光和影只给一个主角时刻
- 规则：层次先靠排版、间距、z 序、明暗对比、景深；辉光只在「一个主角时刻」用一次，阴影只给浅底白卡。
- 数值与证据：B 全片无阴影、无辉光、无 3D，唯一光效是 live 描边（实测是窗口内侧 2–16px 的暖色带，约 0.9s）（B 13.93–15.09s，高）。C 无发光、无运动模糊、无粒子，唯一投影 blur 16–24px、α 0.08–0.12（C 通用规律 7，中）。A 用景深造层次：邻物 blur 4–12px + 变暗，面板 rotateX≈20°，彩色辉光只在搜索条/按钮爆开段（A 约 24–25s）（A 通用规律 4，中）。
- 置信度：**中**（三片一致，但「什么时候用辉光」是归纳）。

## 9. 音效卡操作，不卡音乐拍
- 规则：音效对齐画面上的操作瞬间（按下、回车、落位、节点亮、数字跳），时间轴先按画面定，再贴音效；不把切点量化到音乐拍。我们不做 BGM，所以这层只管操作点。
- 数值：B 19 个关键事件对 82 BPM（拍长 0.729s）取相位，平均绝对偏移 0.15s vs 随机 0.18s → 不卡拍；高通 3kHz 后键击/点击簇与操作对齐（±0.05–0.1s）（B 卡 14，中高）。复测（本 Skill 的 `audio_beat_check.py`，高通 3000、拍长 0.729）：偏移比值 1.08（与随机无异），事件 ±0.1s 内有 onset 37% vs 随机 10%。A：109 BPM 床，切点落在拍内随机位置（A 卡 13，中）。
- 矛盾标注：C 的 12 个场景切换里 10 个以上落在 onset ±0.1s 内，但 onset 密度约 2/s、随机命中率约 40%，且分不清是旁白还是音乐（C 音轨结论，中）。所以 C 只能说「可能贴旁白」，不推翻本规则。
- 大转场强调：「掉电平 → 重击」（A 12.9 / 29.6 / 41.5 / 59.7s 切点前后 RMS 0.13–0.18 → 0.43–0.54）；全片唯一一次留白：A 25.2–26.2s 近静音约 0.9s 后重击，落在报告面板落稳后约 0.2s（中）。我们没有 BGM，可用 SFX 层的 riser/impact 做同样的强调。

## 10. 节奏与留白
- 段长：A 2.5–4s（约 24 段）；B 2–3s（约 14 个镜头）；C 平均 2.8s（12 段）。动作结束后固定停 0.5–1.2s 再切（C 规律 5）。（中）
- 空 → 满 → 空的呼吸：标题段背景几乎全空；UI 段面板占屏 40–60%；辉光段铺满（A 规律 5，中）。
- 同时只有一个视觉主角：主角「黑/白 + 大」，其余低对比；颜色最多三种主色（C 规律 4，中）。

## 11. 隔帧（on twos）点缀
- 规则：局部动效（标题落位、锁屏上升、撞击回位）按 1/12s 量化，带手 K 味；主镜头推拉保持逐帧平滑。
- 证据：B 标题被撞下后 12fps 保持（B 7.72s，像素实测保持帧）；锁屏上升前段成对重复帧（B 36.14s）；C 整片动画是 12fps 放在 24fps 容器里（红笔像素按 1/12s 阶跃）；D 马赛克 10fps、曲线编辑器播放头约 15fps 阶跃（7/14px 交替）。
- 置信度：**中**（B 卡自己也说「手 K 还是导出重复帧」不能完全确定）。

## 12. 爆发式放大（一个词变主角）
- 数值：字间 pill 4 帧加速放大 1.00 → 1.03 → 1.16 → 1.57 → 3.36，随后 2 帧收到 3.47 停住；放大原点固定在 x=1076/1280（D 1042.4–1043.2s，30fps 逐帧重测）。
- 置信度：**高**（推翻了卡片的「首帧跳 2.2× 再指数衰减」）。

## 13. 高级感从哪来（检查清单）
1. 一台相机看一张画布，转场是运镜或形变，不是叠化（第 1、6 节）。
2. 状态 0 帧硬切，入场指数衰减无过冲；大东西 calm、小东西 snappy（第 2、3 节）。
3. 同级元素严格错峰、间隔固定（第 7 节）。
4. 打字和放大是爆发式的，有停顿（第 5、12 节）。
5. 后期克制：光影只给一个主角时刻；先把间距、字体、缓动做对（第 8 节）。
6. 每个动作后有留白，停留段有轻微漂移（第 1、10 节）。
7. 音效贴操作，轻、短，不抢人声（第 9 节；音量与密度规则见 你的Remotion工程 `scripts/sfx_rules.md`）。
8. 细节真实：真实 UI 文字（DOM 渲染，清晰）、点击有按下、数字跟着数据走（D 1130.0s 的计数会停平台甚至回落）。

## 14. 被推翻的结论（教训：单次目视读数不能直接用）

下面每一条都是技法卡（目视 / 拼图读数）写下、后来被独立像素检验证伪的。共同原因：12fps 拼图看不到单帧、阈值选错、采样窗口截短、把别的 fps 的「帧」当成 30fps 的帧、编目时间偏差。**任何数值进积木前，都要用 `measure.py` 在原片像素上独立复测一次。**

数值（示例项目 v6 实测 → S3 旧版 → S3 新版；字高、面积按 1920×1080 画面比例，墨迹 = 字面 + 挤出）：

- 面积：墨迹占画面 示例项目 0.13–0.24；旧版 0.08–0.10（LOW 只有 示例项目 的 0.67 倍，MATTER 0.32 倍）；新版 0.24–0.32（LOW 1.9 倍、MATTER 1.26 倍、RISK 1.9 倍 示例项目），露出部分也比 示例项目 大 1.3–2.5 倍。

- 动效：字母逐个指数上升 0.62 em（k 0.72，错 2 帧，无过冲），整词从 1.07× 缩到 1×（k 0.82，z-push），挤出跟着长出（k 0.78）；示例项目 10%→90% 用 6–7 帧，新版同级。离场字母下沉 0.9 em（ease-in，12 帧，末帧 dur-1）。视差：字层在相机推近时多一个 −1.2% 的慢缩放，读起来比主播远。

**Z4 描边与挤出**：中文字体（尤其思源的可变字体文件）由互相重叠的轮廓组成，直接描边会画出接缝，所以一律只描外半边：画两倍宽的描边，再用字形填充遮罩掉内半边（`ZhOutline`）；描边宽度为字号的 0.8%（英文 1%），至少 2 px，字号小于 150 px 不用纯描边。挤出比英文浅：3D 字 0.045 em（英文 0.072），身后大字 0.03 em（英文 0.05）。置信度：高（第 1 轮视频窗口的接缝现象和修法一一对应，修后 200% 复查干净）。

**Z6 霓虹（中文）**：原片 ex03「独门 小招」是中等字重黑体、奶油暖白芯、暖色外发光，不是圆体招牌；中文霓虹默认用思源黑体 Medium 加暖白。置信度：中（原片证据只有 540P 小格）。

**X3 入场「带着速度出现」，在画面里挪位置才「软起步」。**

**X4 错峰要快、要重叠、要「不齐」。**
数值：间隔 0.03–0.13 s（C 0.074、E01 逐词 0.133、E03 逐字 0.067、D 弹出 0.028）；重叠 0.5–1.0（典型 0.64–0.8）；间隔离散度 CV 0.35–1.1——参考片从来不是等间隔。做法：`overlap 0.8` 推出间隔 = t90×(1−overlap)，再 `jitter 0.75`（每个起点随机偏移 ±0.75×间隔，按种子确定）。

**X5 永不完全静止：主运动衰减到「底速」而不是 0。**
数值：E01 卡片环旋转底速 0.77°/帧（23°/s）一直不为 0；E01 毛玻璃框 4 帧急减速后恒速 ≈700 px/s@1920；A 焦点卡停留段每帧 +0.3% 放大、邻卡 1.3 px/帧漂移；E06 Pay 卡停留时 ±4° 摆动（半周期 1.4 s）；参考片停稳后死静帧占比 0–0.68（大多为 0）。做法：`coast(t, {v0, vBase, k})`（减速到底速）、`coastSettle`、积木默认摄像机 3%/s 推近 + `wiggle(0.35 Hz)` 微漂移。

**X6 惯性回弹表达式：amp = 1/(2π·freq) 时落点速度连续。**
数值：经典 `v·amp·sin(2π·f·t)/e^(d·t)` 在关键帧处的起始速度是 v·amp·2πf；AE 常见默认 amp .05 / freq 4 会让落点瞬间提速 26%。我们的「惯性」预设：关键帧 0→1 用 0.20 s（出点速度 1.3/dur 影响 20%，入点速度 0.5/dur 影响 25%），freq 1.25、decay 8、amp 取连续值；从静止起步的版本 0.30 s。按 E06 区间调参（`scripts/silky_tune.mjs`，FIT）。

**X7 形态连续变形（MorphBox / ShapeMorph）：一个容器，宽、高、圆角各自一条曲线。**
数值：弹簧 stiffness 155 / damping 10（ζ 0.40，T 0.55 s）、起步速度 6 个位移/秒；宽度过冲时高度让位（`squash 0.55`，E06 w·h ±9% 守恒）；圆角 ≈0.21×短边（短于 220 px 的条用全圆角）；`anchor:'top'` 顶边不动向下长（E09）；旧内容在容器动之前 0.04 s 开始糊化淡出，新内容晚 0.08 s 出现并由模糊变清晰；收起用 6250 px/s 匀速后硬停（E06 −230 px/帧@2118），不回弹；右/底锚定的子元素跟着边走。

**X8 卡片环：整环是一个图层，相似变换 = 底速旋转 + 衰减的多余转速 + 从约 2× 慢慢缩小，最后加速塌缩。**

**X9 跨硬切延续：切点前加速缩小 + 旋转，切点后新主体从「过大」继续同向缩小 + 旋转。**

## 22. 实景丝滑转场：速度和视线都不断（2026-10-23，R2 重庆 vlog 得出）
> 逐切点测量见 `vlog-ui-fusion-and-transitions.md` 第二部分。

- 规则：几乎全是硬切，丝滑来自 ① **速度不断**：出镜头加速，在最快那一帧切，入镜头带同方向同量级的速度进来再减速（速度接力 / 整帧推入）；② **视线不断**：视线焦点切前切后同位置（匹配剪），或用画面里本来就有的边扫过去（遮挡擦除），或点一下屏幕进入下一镜。
- 数值：入镜头 7–9 帧（0.23–0.3 s）近匀减速到 0；整帧推入 7 帧推完约 0.7H（136 → 7 px/帧）；停稳后反向慢漂（同 X5）。
- 来源：R2 1.90/3.00/3.90/5.40/8.00/10.50/13.67 s（录屏 30fps，相位相关逐帧测位移）。
- 置信度：结构 **中高**；数值 **中**（录屏低清，±4 px）。
- 落地：B-roll 段优先用速度接力和匹配剪；两镜各做位移，切点处出镜 easeIn、入镜 easeOut，峰值对齐。
