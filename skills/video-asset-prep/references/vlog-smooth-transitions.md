# 技法卡：实景 vlog 的丝滑转场（R1 / R2）

> 来源：两条抖音热门 vlog 的手机录屏（2026-10-23 入库），评论区一致叫它们「神级转场」。只有录屏，没有原片：画面里叠着抖音界面，分辨率低（R1 560×1280、R2 720×800，30fps），时间是录屏秒数。
> 视频代号：**R1** 城市 vlog（香港，约 14.6 s 一轮循环）；**R2** 城市 vlog（重庆雨天，约 19.5 s 一轮）。两条都是零口播，只有音乐。
> 测法：每个切点前后 ±0.5 s 逐帧抽图看衔接方式；整帧位移用相位相关逐帧测（160 px 宽代理，精度约 ±4 px，下文换算成画面宽 W / 高 H 的比例）；帧差找切点。
> 何时读：B-roll 段要换镜头、又不想用剪映自带转场的时候。

## 0. 一句话总结

丝滑的关键是**镜头之间不断速度、不断视线**：要么让运动从上一个镜头接力到下一个镜头（在最快的那一帧切，下一镜带着同样的速度进来再减速），要么让观众盯着的那个东西（手、杯子、旗子、鸟、边缘）在切点前后留在同一个位置。转场本身几乎都是硬切，没有叠化，也没有剪映式的特效转场。

## 2. 规律

### S1 速度接力：在最快的一帧切
- 规则：出镜头的运动（摇镜、甩手、甩伞、人物扫过）**加速**到最快，在峰值那一帧切；入镜头**带着同方向、同量级的速度**进来，再减速停住。速度曲线在切点连续，眼睛就不觉得切了。
- 数值：出镜头加速约 0.2–0.25 s（R1 7.70 前 7 帧从 6 加到 76 px/帧）；入镜头 7–9 帧（0.23–0.3 s）减速到 0，减速接近匀减速（每帧少 3–6% 画面高）；峰值 0.16W/帧（R1）～0.24H/帧（R2 1.90）。
- 证据：R1 7.70、10.57、11.53；R2 1.90、3.00、8.00。
- 置信度：中（录屏代理测量，±4 px）。
- 和已有规则：principles X3「入场带着速度出现」和 X9「跨硬切延续」的实景版。X9 是元素跨切，这里是整帧跨切。

### S2 整帧推入：下一镜当成一张卡片推进来
- 规则：不用叠化，把下一镜整张从画面边缘推进来，边界留一条 1–2 px 的细亮线，推到位后 easeOut 停住。
- 数值：R2 1.90：7 帧推完约 0.7H，首帧速度最大。
- 证据：R2 1.90。置信度：中。

### S3 匹配剪：盯住的东西不挪位
- 规则：切点前后，画面上最吸引视线的东西（手和杯子、旗子、鸟、飞机）**在同一个屏幕位置、同样大小**，只换背景。
- 证据：R2 13.67（手 + 杯子，最典型）；R1 13.73（红旗）；R1 12.57（屏幕里的鸟 → 现实的鸟）；R1 1.07（飞机 → 鸟）。
- 置信度：高（画面清楚）。
- 拍法：同一只手、同一个杯子在不同地点各拍一段，构图对齐。剪辑时用上一镜最后一帧做半透明参考对位。

### S4 遮挡擦除：用画面里本来就有的边
- 规则：让一个前景的边缘（门框、屏幕边、叶子、伞、扫过的手）扫过画面，边缘后面就是下一镜。擦除线跟着运动走，不是一条凭空出现的直线。
- 证据：R1 7.70（手）、10.57（门框）、11.53（压进黑暗）；R2 3.90（叶子）、8.00（棚顶边）、10.50（屏幕竖边）。
- 置信度：中。

### S5 常驻层：一层不动，底下换
- 规则：画面上叠一层跟内容有关的东西（R1 是手机控制中心的播放卡和滑块），底下的实景硬切，这一层留在原位，视线就有了落点。
- 证据：R1 6.70（渡轮 → 猫，UI 不动）。退场时只让这一层碎成噪点块，约 0.4 s（R1 7.5–7.9 s）。
- 置信度：中。
- 注意：常驻层必须少而克制（R1 只有一张卡 + 两三个滑块）。

### S6 点击进入
- 规则：手点屏幕上的一个图标，点下处放大成下一镜，前景的手留着。
- 证据：R2 5.40。置信度：中。

### S7 切完不静止
- 规则：入镜头停稳后，镜头继续慢慢漂（常常是反方向，约 0.01–0.03H/帧），不会死住。
- 证据：R2 1.90 后 +10～+18 px/帧，R2 3.00 后 −7～−10 px/帧。
- 和已有规则：X5「永不完全静止」。

## 3. 反面例子：R2 的金鱼

paxon 的判断（2026-10-23）：金鱼是这条片子的**败笔**。我们这边的理由：
- 金鱼是贴上去的 3D 素材，和实景的光线、景深、雨天色调都不统一，一看就是贴纸；
- 数量太多（高潮段 15 条以上、盖住约 40% 画面），把真正好看的转场挡住了；
- 它和镜头内容没有关系，只是对歌名《美人鱼》的字面联想。

**教训**：常驻层（S5）可以用，但要和内容有关、要少、要克制；不要为了「有东西贯穿」去满屏堆贴纸元素。抽帧时也别被画面里最显眼的东西带偏，先看切点前后的速度和位置。

## 4. 选题和钩子

- 评论和弹幕几乎都是「神级转场 / 百万剪辑 / 剪得太好看了 / 出模板吧哥」。观众来夸、来要同款，不是来争论的。
- 数据形状（估计，两条样本）：转发 / 点赞 18–21%，收藏 / 点赞 8–10%，评论 / 点赞 0.4–2.4%。技法展示类带的是转发和收藏。
- 候选第 ⑧ 个「想」：**想要同款 / 想学会**（收藏、转发、求模板）。置信度低，待验证。
- 给我们的选题：「我让 Claude 复刻了抖音百万剪辑的丝滑转场」：开头放复刻成品（② 看结果），中段原片和复刻并排（④ 辨真伪），结尾「要模板的扣 1」（⑧ 想要同款）。

## 5. 用到我们的片子里

- 横屏口播片的 B-roll 段：S1 速度接力和 S3 匹配剪最值得学，Remotion 里两个镜头各自做位移动画，切点处速度对齐即可（出镜头 easeIn、入镜头 easeOut，峰值同向同量级）。
- S2 整帧推入可以替代剪映自带的转场。
- 复刻只作内部学习，不进成片。
