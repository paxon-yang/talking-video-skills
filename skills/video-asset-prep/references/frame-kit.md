# 固定框架：做一次，所有视频共用
- **字幕胶囊**：奶白或深石墨胶囊 + 左侧头像 + 粗体字 + 重点词高亮色；同一句连续行只换字和宽度；字幕层不跟相机；深色胶囊+白字+亮绿重点词在浅底对比度最高（白字约 14:1、亮绿约 9:1）。
- **背景**：浅色（奶油纸底 + 颗粒 + 柔光斑 + 暖色暗角）和暗色（暖暗书房 / 网格）各一版；浅色界面里不放深色大块，暗区只用小面积胶囊。
- **配色**：强调色 ≤3；不用紫色霓虹线（可用紫色像素占比 <0.2% 自检）。
- **字体**：中文标题粗黑；钩子 / 问句用宋体；标签用有个性的展示体；同屏最多 2 种字体。
- **封面模板**：横版 1920×1080 + 竖版 1080×1920，各一张主图 + 一张备选；标题 ≤6 个字，关键词用强调色加描边；缩到缩略图尺寸检查仍可读。
- **打字机**：所有打字都做逐字出现 + 闪烁光标，并登记（起帧、文字、每字帧数）供键声生成。
