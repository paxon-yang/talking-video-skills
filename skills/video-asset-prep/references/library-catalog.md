# 素材库目录：让「做片时选素材」查得到、选得准

备料攒下的东西越来越多（积木、规律、风格、原始素材），做片时如果只靠记忆去翻源码，选出来的永远是最近做过的那几个。所以每一样资产入库时都要登记一条目录，**目录是给「选素材」用的，不是给「找文件」用的**：重点写它适合表达什么，而不只是它叫什么。

制作 skill 开工第一步就读这份目录（见 `../../talking-video-oneshot/references/asset-selection.md`）。

## 1. 四个库

| 库 | 装什么 | 例子 | 目录文件 |
|---|---|---|---|
| 积木库 | 带参数、可直接渲染的 Remotion 组件 | 卡片环绕、灵动岛形变、身后大字、打字机、2.5D 图标、步骤线 | `<工程目录>/library/blocks.md` |
| 规律库 | 带数值和置信度的动效 / 节奏 / 舒适度规律 | 缓动两档、错峰、点击反馈、主播回归频率 | `principles.md`（本 skill）+ 自己的增补 |
| 风格库 | 一整套可整片套用的视觉方案 | 淡色纸张一镜到底、暖暗书房 + 数字人、奶油底 + 白磨砂卡 | `<工程目录>/library/styles.md` |
| 素材库 | 原始材料：参考视频、技法卡、B-roll、AI 图、头像贴纸、音效 | 学习素材录屏、Pexels 实景、Gemini 背景 | `<工程目录>/library/materials.md` |

四个文件放同一个 `library/` 目录，网盘同步一份，方便在别的会话或手机上看。

## 2. 每条目录写什么

### 积木（一块一条）
```markdown
### B-023 卡片环绕（CardOrbit）
- 适合表达：并列要点 / 多个案例 / 「我有很多 X」的丰富感
- 不适合：严格的先后顺序（用步骤线）、只有 1–2 项
- 情绪与节奏：轻快、展示感；单次 2.5–4 s
- 画面：3–8 张卡绕中心旋转，当前卡放大发光
- 关键参数：items[], radius, speed, focusIndex, theme(light|dark)
- 适配风格：S-01 纸张、S-02 暖暗（暗色要换卡片底）
- 能否和主播同框：能（主播小窗时放右侧 60%）
- 校准：复刻 SSIM 0.87（参考 D 811 s），见 VERIFY
- 预览：library/previews/B-023.gif
- 用过：视频1 第 7 句；视频3 第 22 刀
- 来源：D 录屏 811–832 s 拆解，2026-10-19
```

### 规律（沿用 principles.md 的写法）
规则 → 数值 → 来源 → 置信度，另加一行 **「选素材时怎么用」**（例：「同一片里身后大字 ≤3 次、不连续」直接约束选型）。

### 风格（一套一条）
```markdown
### S-01 淡色纸张一镜到底
- 适合：软件 / 开源项目宣传、教程、讲方法；无数字人或数字人小窗
- 不适合：情绪重、需要实景氛围的话题
- 底：暖白纸张 + 点阵 + 颗粒；字幕：白胶囊 + 头像贴纸
- 配套积木：B-003 一镜到底转场、B-011 发布会标题、B-019 彩色厚底卡……
- 禁忌：黑底、纯白、速度线开场
- 代表作：视频2 v2、claude-agent-tools 宣传片
```

### 原始素材（一份一条）
```markdown
### M-2026-10-21-a 录屏 21-28-38（21.6 MB）
- 位置：网盘 douyin/学习素材/Record_2026-10-21-21-28-38_….mp4
- 内容：一句话描述 + 看点时间段
- 状态：未拆 / 已编目 / 已深拆（技法卡链接）/ 已沉淀（产出的积木、规律编号）
- 可直接用进成片吗：否（第三方内容只作学习）/ 是（自己拍的、免版权实景）
```

## 3. 标签词表（选型靠它匹配）

「适合表达」尽量从下面挑词，选素材时按词匹配；新词可以加，但先查有没有同义词。

- **内容类型**：钩子 / 反问、论点、对比（前后、A vs B、三方）、流程步骤、并列要点、关键数字、趋势、构成占比、时间线、因果、比喻故事、产品演示、产出展示、金句、总结、行动号召
- **情绪**：抓人、惊讶、紧张、轻快、克制、高级、温暖、幽默、严肃
- **节奏**：冲击（≤1 次 / 片）、快切、平稳、停留
- **主播关系**：主播全屏、小窗、同框互动（被挡、从身前过）、无主播

## 4. 什么时候写目录（入库闸）

1. **学完一条参考素材**（method-dissect 第 6 步出了技法卡）→ 在 materials.md 把状态改成「已深拆」，链接技法卡。
2. **做成一块新积木或调好一块旧积木**（method-replicate 通过）→ 在 blocks.md 新增 / 更新一条，**没有目录条目的积木不算入库**。
3. **一支视频交付后** → 给用到的积木补「用过」，新风格补进 styles.md，被否掉的做法写进对应条目的「不适合」。
4. 每月看一次：长期没用过的积木写明原因（过时 / 太难调 / 和风格冲突），该删就删。

## 5. 检查
- 每块积木都有「适合表达」和预览图。
- 素材库里没有状态为空的条目。
- 三个目录文件互相引用的编号都存在（B-xxx、S-xx、M-xxx）。
