# 三套内容模板与时间表（60s / 120s / 180s）

> 字数按 5.0–5.5 字/秒（含停顿实际 4.5–5）：60s ≈ 280–320 字，120s ≈ 560–640 字，180s ≈ 850–960 字（数据型可到 6.0 字/秒）。
> 组件名对应 remotion-pipeline.md；剪映路径用 jianying-guide.md 的对应手法。字数预算 = 段落秒数 × 4.8（取整到 5，估算值，非原片实测）。
> 带"（估计）"的是推算值，不是实测。

## 选哪套

| 内容 | 模板 | 判据 |
|---|---|---|
| 工具测评 / 教程 | A | 有可演示的界面，有一个可测的数字 |
| 观点 / 解读 | B | 有类比案例、有反转，无界面也行 |
| 数据 / 事件 | C | 有金额/比例/时间线可画图 |

## 通用写法

- 每个模板的**开头 20–30s 最密**（≥5 刀、2–3 贴字），之后"15s 紧（4–6 刀）+ 15–20s 松（1–2 刀）"。
- 每段结尾回主播大景一次；大景每 15–20s 回归，单次 3–6s。
- 数字单独成句；CTA 只在结尾出现一次。
- 1 分钟版先砍"可选"，再压"应当"，"必须"不动。
