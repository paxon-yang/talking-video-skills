# "看着舒服"的 11 条规律（量化）与检查方法

> 数据：博主A 9 集（原速约 96 分钟）+ 博主B 3 集（约 54 分钟），统一口径。时间为原速秒，30fps。
> 一句话：**剪辑跟着嘴走；固定框架里只换内容；运镜少而有目的。** 观众的眼睛不需要重新找东西。
> 每条给：规律 → 数值 → 复刻动作 → 检查方法（lint = `npm run lint:timeline` 的哪一条；手查 = 剪映/成片目视）。

## 1. 切点卡在换句上（最重要）
- 博主A切点处换句比例 59–80%（中位约 69%；随机时刻 16–33%）；博主B 70–88%（随机 40–50%）。
- **复刻**：镜头起点 = 句子起点帧（±3 帧）；Remotion 里 Scene.from = 首句 start。目标 ≥69%，下限 55%。
- **检查**：lint「切点落在句首 ±3 帧比例」（planner 直接按句首生成，恒为 1.00，所以**真实成片必须实测**）；手查：逐个切点看字幕是否同时换句。

## 2. 不是每句都切，平均两三句一个画面
- 换句时 ±0.2s 内有切点的比例：博主A 9–49%（多数 20–32%，随机 5–14%）；博主B 32–62%。检测段长中位：博主A 2.0–2.5s，博主B 1.6–2.0s；博主A人工镜头中位 3.6s（P10 1.3，P90 11.3）。
- **复刻**：1–3 分钟片每 2–3 句（约 4–7s）一个主画面，中间用叠加贴字制造变化，不硬切。
- **检查**：lint「刀/分钟」12–20（数据型到 24）；手查：数一分钟内的镜头数。

## 3. 关键词贴字在"说到这个词"时出现
- 贴字比所在字幕行晚，中位 +0.67s；相对"说出该词"时刻偏差中位 +0.07s，45% 落在 ±0.5s；**早于字幕的仅 6%，早出 ≤11%**。
- **复刻**：词级时间戳，贴字 `from` = 关键词开始帧 −2~+4（默认 +2）；宁晚勿早；只有句级时间戳时 +4 并标 confidence 0.5。
- **检查**：lint「贴字偏移范围 −2~+4 帧」；手查：贴字不得比口播早。

## 4. 不同画面类型给不同时长（博主A 1059 个镜头）
| 类型 | 时长占比 | 中位(s) | P10 | P90 |
|---|---|---|---|---|
| 屏幕录制 + PIP | 44% | 7.3 | 2.2 | 21.9 |
| 主播 | 19% | 4.8 | 1.7 | 9.9 |
| B-roll / 素材 / 3D | 17% | 2.4 | 1.1 | 5.9 |
| 图文卡 | 17% | 3.0 | 1.4 | 9.4 |
| 成片全屏 | 3% | 1.9 | 0.7 | 3.7 |
- **复刻（1–3 分钟）**：主播 3–6s；B-roll 1.5–3s 可两三张连切；关键词/图卡 1.5–3s（≤4）；演示录屏 5–10s（中间必须有运镜或标注）；成片全屏 1–4s。
- **检查**：lint「大景单段 3–6s（≤8 可接受）」「>5s 录屏/素材镜头有运镜」。

## 5. 紧—松交替，没有长时间"死水"
- 每 10s 切点数高于本集均值算"紧"。博主A紧段中位 10–20s，松段 10–30s，整集约 16 刀/分（长演示集 6.8–9.8）；博主B 25–30 刀/分，**没有一个 10 秒窗口是 0 刀**；博主A 0 刀窗口占 2–24%。
- **复刻**：3 分钟片按"15s 紧（4–6 刀）+ 15–20s 松（1–2 刀，靠运镜和贴字维持）"循环；开头 20–30s 全片最密；10 秒窗口零切点 ≤10%。
- **检查**：lint「10s 零切点窗口占比」≤0.10。

## 6. 主播定期回来，"无人脸"不超约 10 秒
| 指标 | 博主A | 博主B |
|---|---|---|
| 主播可见（含 PIP/小窗） | 59–91% | 73–88% |
| 大景（脸高 ≥22%H）占比 | 13–43% | 42–52% |
| 大景回归频率 | 1.4–4.4 次/分 | 4.3–5.6 次/分 |
| 大景单段时长 | 中位 4–8s | 中位 4–5s |
| 连续无脸段 | 中位 1–5s，P90 2–14s | 中位 2s，P90 4–7s |
| 大景人脸构图 | cx≈0.48，cy≈0.34–0.44，脸高≈0.30H | cx≈0.54，cy≈0.25，脸高≈0.33H |
- **复刻**：数字人大景每 15–20s 回来一次，单次 3–6s；其余保留 PIP；纯素材段 ≤8–10s。
- **检查**：lint「最长无脸段(s)」≤10；「大景最大间隔(s)」≤22（目标 15–20）。手查：用秒表数连续看不到主播脸的最长时间。

## 7. 动效时长有档位：硬切、约 6 帧、约 12–14 帧
- 见 motion-and-camera.md §1。常量 `HARD=0`、`FAST=6`、`STD=12` 帧；停留 ≥40 帧；出场硬切或 6 帧淡出；叠化只在换段，12–15 帧。
- **检查**：lint「贴字停留 ≥40 帧」；手查：新做的动画是否落在 0/6/12 帧（剪映里 0 / 0.2s / 0.4s 近似，见 jianying-guide.md §6）。

## 8. 字幕是全片最"钉死"的元素
| 指标 | 博主A | 博主B |
|---|---|---|
| 字幕中心 y | 0.898–0.92（ex03 0.934） | 0.886–0.896 |
| y 标准差 | 0.010–0.036（多数 ≤0.013） | 0.004–0.011 |
| 文字高 | ≈0.062H | ≈0.081H |
- **复刻**：字幕绝对定位、水平居中，全片一种样式；成片全屏段撤掉字幕。Remotion 取 y 0.905 / 46px；通过线：y 标准差 ≤0.013。
- **检查**：lint「字幕行 ≤14 字」「字幕不重叠」；手查：快速拖动时间线看字幕是否上下跳。

## 9. 画面信息少，大字走中轴和三分线
- 非字幕文字块每帧中位 0–6 块，P90 4–20；文字面积中位 1–2%；视觉块中位 0–1。大字（h≥6%H）中心 x：0.45–0.55 最大（27%），左三分区 0.2–0.4 约 20%，右三分区 0.6–0.8 约 22%；字高中位 0.084H，P90 0.148H。
- **复刻**：一屏最多 1 个主标题 + 3–4 要素；主标题字高 0.08–0.14H；安全边距 5%，角标可贴 1–3%。
- **检查**：手查（lint 暂无）：任意暂停一帧，数文字块≤4，主标题 ≤1。

## 10. 底色统一偏暗、主色少；切点不刻意匹配亮度
- 平均亮度 Y：博主A口播/图卡集 42–62（暗底），录屏白底集 96–132；博主B 88–113。主色 4–6 个。切点前后 |ΔY| 中位 10–37（不平滑亮度）。"压暗再切"博主A每集 0–9 次；软转场博主A 0–1.9 次/分，博主B 1.4–3.1 次/分。
- **复刻**：全片只用两种底——深色网格 #010101 或压暗 B-roll（亮度保留 20–45%）；强调色 ≤3；叠化只在换段，12–15 帧，1–3 分钟片 ≤2 次；"压暗再切"每片 ≤1。
- **检查**：手查：颜色数；转场次数。

## 11. 长镜头靠"微运镜"续命
- 博主A录屏镜头中位 7.3s，期间检测到 87 次推拉、36 次平移；PIP、阶段标签、字幕不跟着动。
- **复刻**：录屏镜头每 3–5s 一次"推到要讲的区域"或"拉回全局"；运镜只作用于录屏层；推近 1→1.12、26–32 帧 inOutCubic。
- **检查**：lint「运镜时长/幅度在实测范围」「>5s 录屏/素材镜头有运镜」「punch-in 次数/分」≤2。

## lint 15 条一览（`<工程目录>/src/lint.ts`，全部 PASS 才算过）
1. scenes 首尾相接且铺满（第一个 from=0，from+dur=下一 from，末尾=durationInFrames）
2. 切点落在句首 ±3 帧比例 ≥0.55（目标 0.69）
3. 刀/分钟 12–20
4. 最长无脸段 ≤10s
5. 大景最大间隔 ≤22s（目标 15–20s）
6. 大景单段 3–6s（lint 容忍 2.8–8s）
7. 10s 零切点窗口占比 ≤0.10（步长 5s）
8. punch-in 次数/分 ≤2
9. 字幕行 ≤14 字（不含标点）
10. 字幕不重叠
11. 贴字偏移范围 −2~+4 帧（trigger.offsetFrames）
12. 贴字停留 ≥40 帧（被镜头边界截断除外）
13. content 层标注不跨镜头
14. 运镜时长/幅度在实测范围（push/pull 20–40、pan 14–30、punch 14–26、rush_in 12–20、kenburns 45–150、tilt3d 20–40；scale ≤1.42；punch ≤1.13）
15. >5s 的 screen_demo/broll 必须有 camera

**lint 通过 ≠ 像他们**：lint 保证"不违反舒适规律"，气质仍靠主观 A/B。

## 通过线（成片级，渲染后实测，需用 analysis_comfort 脚本；手工路径抽查）
| 指标 | 通过线 |
|---|---|
| 切点换句率 | ≥55%（目标 69%） |
| 字幕 y 标准差 | ≤0.013 |
| 入场时长落在 0/6/12±2 帧比例 | ≥75%（估计） |
| 最长无脸段 | ≤10s（P90 ≤14） |
| 大景回归间隔 | 15–20s |
| 贴字早出比例 | ≤11% |
| 10s 零切点窗口 | ≤10% |
| 刀/分 | 12–20（数据型到 24） |

## 必须 / 应当 / 可选（压缩时的取舍依据）
| 级别 | 项目 |
|---|---|
| **必须** | 暗底固定模板；字幕钉死（一个样式）；切点对齐句子（≥60% 落在句首 ±3 帧）；2–3 句一个主画面；贴字跟词（−2~+4 帧）；动效落入 0/6/12 帧档位；开头 3 秒钩子；大景每 15–20s 回归；无脸段 ≤10s；静态素材全部慢推；运镜只作用于内容层且幅度 ≤1.12；强调色 ≤3；PIP 只在证据段出现；一屏 ≤1 主标题 + 3–4 要素 |
| **应当** | 紧松循环；开头 20–30s 最密；关键词卡 1 帧硬切；录屏每 3–5s 一次运镜或标注；章节 HUD；以前/现在对比；总结卡逐条点亮 |
| **可选** | 夹头词（教程型强烈建议）；punch-in；成品预告；3D 卡通比喻；宽银幕情绪段 + 毛笔大字；数据型图表；章节角标；喊话放大；叠化转场；片尾账号卡（不要）；人物抠像 + 姓名条；新闻拼贴；聚光灯 |

## 与"一般业余剪辑"对照（业余一栏为常见问题描述，未实测）
| 业余常见做法 | 为什么累 | 本风格做法 |
|---|---|---|
| 按固定秒数或随手切，切在句子中间 | 画面与语义各走各的 | 59–88% 切点落在换句处 |
| 每句都切，或一个画面挂 30 秒 | 前者碎，后者闷 | 2–3 句一个画面；无脸段 P90 ≤14s |
| 贴字整句一起出或比口播早 | 先读到字再听到声 | 贴字跟词，早出 ≤11% |
| 动效时长随意混用 | 节奏感乱 | 档位集中在 0/6/12 帧 |
| 字幕位置/字号随场景变 | 眼睛每次重新找字幕 | y 标准差多数 ≤0.013 |
| 一屏塞满字和贴纸 | 信息过载 | 文字面积中位 1–2% |
| 大量缩放、旋转、甩镜转场 | 晕、廉价感 | 推近只到 1.06–1.12；带运动切点仅 9–11% |
| 静态截图直接放着 | 画面"死" | 所有素材线性慢推 |
| 运镜时 PIP、字幕一起缩放 | 参照物丢失 | 运镜只作用于内容层 |
| 色彩杂、每段换风格 | 不像同一作品 | 主色 4–6 档，标签色 ≤3 |
