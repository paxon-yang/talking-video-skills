# 剪映执行手册（路径 A：不用 Remotion，手工剪辑也能做出这个风格）

> 适用：剪映专业版（电脑端）。**菜单名、滑块范围、坐标正负号随版本变化，本手册凡标"需按版本确认"的需要第一次实际点一遍核对；** 数值目标（秒数、比例、色值）来自 Remotion 校准值，是不变的。
> 像素 ↔ 比例：画布 1920×1080；x 比例×1920，y 比例×1080。1 帧 = 1/30s ≈ 0.033s；6 帧 = 0.2s；12 帧 = 0.4s；18 帧 = 0.6s；28 帧 ≈ 0.93s。

## 0. 项目设置（一次做对）
1. 新建草稿 → 比例 **16:9**，分辨率 **1920×1080**，帧率 **30fps**（设置里改；数字人视频也应是 30fps）。
2. 轨道规划（从下到上，对应 Remotion 图层顺序）：
   - 主轨：数字人大景 + 各种全屏素材（录屏、B-roll、关键词卡底）——**按句子切**。
   - 画中画轨 1：圆形 PIP 数字人（同一条口播视频的再放）。
   - 画中画轨 2：录屏面板 / 对比卡 / 图卡。
   - 文本轨 1：HUD 与章节标签；文本轨 2：夹头词/关键词/药丸；文本轨 3：字幕。
   - 音频轨：口播（来自数字人视频）、配乐、音效。
3. 先把数字人视频放主轨，**不要改速度**；其余一切对着它的时间线做。

## 1. 先出"句子时间表"，再剪（"跟着嘴走"的关键）
1. 数字人视频放主轨 → 文本 → **智能字幕/识别字幕**（或"文稿匹配"，把口播稿贴进去）→ 得到按句分好的字幕。
2. 检查每行 ≤14 字（不含标点）、8–10 字最佳；超长行手动拆；句中停顿用**空格**，去掉句内标点，句末保留"？"。
3. **每一个切点（换镜头）必须落在某一行字幕的起点帧 ±3 帧（≈±0.1s）**；做法：把播放头吸附到字幕左端（开启"吸附"），再"分割"。
4. 每 2–3 句换一个主画面（4–7s），不要每句都切。

## 2. 字幕样式（全片一种）
| 项 | 设置（博主A主题） | 说明 |
|---|---|---|
| 字体 | 思源黑体 Bold 或同级粗黑体（可商用） | |
| 字号 | **以宽度校准**：10 个汉字占画面宽 ≈ 0.23W（≈440px，字号≈46px@1080p）| 剪映字号数值与像素非 1:1，先放 10 个字看宽度；需按版本确认 |
| 颜色 | 白 #FFFFFF，无描边 | |
| 背景 | 开启"背景"：黑色、透明度 **80%**、圆角（小，约 6px）、上下内边距≈14px、左右≈12px | 框高约 76px；需按版本确认各滑块 |
| 位置 | 水平居中；**文字中心 y ≈ 0.90H（距顶 ≈ 970px，距底 ≈ 9–10%）**；之后**全片所有字幕批量套同一样式、不动位置** | Remotion 取 0.905 |
| 入出场 | **不加动画**（整句硬切） | |
| 博主B 变体（可选，整片统一） | 白字 + 黑描边（约 2–4px）、无背景、字号 ≈56px（10 字≈0.29W）、中心 y ≈ 0.885H | 不与上面混用 |
| 宽银幕段 | 字幕保持同一位置，落在下黑边内 | |
| 成片全屏段 | 该段**删掉或隐藏**字幕 | |
操作：做好第一条后"保存为预设/应用到全部字幕"（需按版本确认入口）。

## 3. 数字人大景与 PIP
- **大景**：主轨全屏。构图在数字人生成阶段定好（cx≈0.48，cy≈0.34–0.44，脸高≈0.30H，见 digital-human.md）；后期不要改位置。
- **圆形 PIP（默认）**：
  1. 把同一条数字人视频再拖到画中画轨，时间对齐（左对齐到该镜头起点，保持与主轨同一时刻，口型才一致）。
  2. 画面 → 蒙版 → **圆形**；羽化 0；调到正圆。
  3. 缩放使直径 ≈ **0.14W = 269px**；位置使圆心在 **(0.08W, 0.85H) = (154px, 918px)**（距画面左上角）。剪映位置是以画面中心为原点的偏移：X ≈ −806px，Y ≈ 378px 向下（**Y 正负号需按版本确认**）。
  4. 脸要在圆心：把视频放大约 1.8 倍并让脸居圆中（Remotion 即放大 1.8 倍，锚点在脸 (0.48, 0.38)）。
  5. 紫环：在 PIP 下方再放一层**比它大 8px 直径的圆形蒙版色块**（#A818B0，外发光可用"阴影/发光"，估计 18px）；剪映没有蒙版描边时用这个办法。博主B 主题不要环。
  6. 连续镜头里 PIP **不重新入场**：把 PIP 片段跨过多个镜头一条放到底，别每个镜头一段。
- **其他预设**：大号 0.17W、圆心 (0.12, 0.80)；小号 0.13W、圆心 (0.92, 0.80)；矩形竖卡 x 0.81–0.97、y 0.52–0.95（矩形蒙版 + 小圆角）。切换预设用位置/缩放关键帧，时长 ≈ 0.4s。
- PIP 只在录屏、对比、图表、数字段出现；概念卡、情绪段、章节卡、总结卡、成片全屏时**删掉**。

## 4. 关键帧：推镜、punch-in、慢推
所有关键帧在 画面 → 基础 → 缩放/位置 点"◇"打点。**只给内容层（录屏、B-roll、数字人大景）打，PIP、字幕、HUD、固定贴字不打**。

| 运镜 | 关键帧做法 | 数值 |
|---|---|---|
| 录屏推近 | 起点帧缩放 100% → 终点帧 **112%**；两点相隔 **28 帧 ≈ 0.93s**；缓动选"缓入缓出/ease-in-out"（剪映关键帧曲线 / 速度曲线，需按版本确认）；推近中心：用位置补偿，使目标 UI 保持在视野（放大后把位置反向偏移） | 起点 = 说到该元素前约 **8 帧（≈0.27s）**；每 3–5s 一次 |
| 录屏拉远 | 112% → 100% | 26 帧 |
| 录屏平移 | 位置关键帧，位移 8–14%，22 帧，缓入缓出 | |
| 主播 punch-in | 100% → **108%**，20 帧（≈0.67s），**缓出**；推后**保持到切点**；中心偏脸（原点 (0.5, 0.38)） | 每分钟 ≤2 次，仅关键句；起点 = 关键句开始 +0–6 帧 |
| B-roll/图片慢推 | 整个片段首帧 100% → 末帧 **108%**，**线性**（关键帧曲线选"线性"） | 相邻两张一推一拉交替；拉：110% → 100% |
| 博主B 风格呼吸 | ±4–5%，30 帧线性 | 可选 |
| 切点冲入（可选） | 新镜头首帧 104% → 100%，16 帧缓出 | 仅约 10% 的切点 |

剪映里"放大"关键帧默认可能是线性——**录屏推近要改成缓入缓出，B-roll 慢推要保持线性**，这是两种不同手感。

## 5. 录屏镜头与标注
1. 录屏放主轨（或画中画轨 2）。要做"面板"：缩放到 **宽 0.85W、高 0.855H**，位置 x 0.12、y 0.015（左上角），圆角 ≈12px（蒙版：矩形 + 圆角），外层垫网格底（见 §6.3）。
2. 镜头长度 5–10s，每 3–5s 做一次 §4 的推拉。
3. **标注框**：
   - 方式一：文本/贴纸里的矩形虚线框素材；
   - 方式二：新建"矩形"素材，描边 **6px 虚线 #FF7A00**（0.4–0.6 不透明度填充可为 0），圆角 6px；
   - 绿色勾标签：白底圆角 8px 黑粗体 ≈60px，勾方块 #00B900；
   - 橙色三角箭头 #FB8B03（≈90×130px），**做上下 ±8px、周期 1s 的循环位移关键帧**（可省略）。
   - 入场：**0.2s（6 帧）"弹入/放大"**；多个标签依次间隔 9 帧（0.3s）。
   - **标注要和录屏一起推拉**：把标注与录屏**合成一个"复合片段"**再打缩放关键帧（需按版本确认"复合片段"入口），否则推镜时框会飘走。
4. 聚光灯：复制一层录屏，下层加"模糊 8"+"亮度 −50%"，上层用矩形蒙版露出焦点；加橙底白字引号标签。

## 6. 文字、卡片与动画
### 6.1 文字入场动画怎么选（文本 → 动画 → 入场）
| 元素 | 剪映动画 | 时长 | 对应 Remotion 档位 |
|---|---|---|---|
| 关键词卡、章节卡、问句卡、数字卡 | **不加**（硬切） | 0 | HARD |
| 叠加贴字、标签、callout | "弹入/放大"类 | **0.2s** | FAST 6 帧 |
| 夹头词、药丸、卡片 | "模糊/渐显 + 放大" | **0.4s** | STD 12 帧 |
| 图卡缩放入场 | "缩小/放大"入场 + 模糊 | 0.6s | SLOW 18 帧 |
| 博主B 风格贴字 | "渐显/模糊" | 0.6–0.7s | |
| 出场 | 默认不加（硬切）；或"渐隐" 0.2s | | 6 帧 |
- 贴字停留 ≥1.3s（40 帧）；**入场帧 = 关键词开始 +2 帧（≈0.07s），宁晚勿早**；贴字出现要在口播说到该词之后，不能先于声音。
- **动画时长以"秒"设**；同一类元素的动画、时长全片统一，不要这个 0.3 那个 0.5。

### 6.2 各元素做法
| 元素 | 剪映做法 |
|---|---|
| **夹头词** | 两条文本：左词右对齐落在 x≈0.305W（586px），右词左对齐落在 x≈0.667W（1281px），中心 y≈0.245H（265px）；字体粗黑体 ≈240px（视觉字高 ≈0.23H，横向压扁到 80% 更像原片）；颜色白/红/荧光绿/黄；加深色阴影；入场 0.4s 模糊+放大；停留 2–5s；出场硬切 |
| **关键词卡（grid）** | 主轨放 §6.3 网格底，文本居中（中心 y≈0.50H），粗黑体字高≈0.135H（≈168px），字距略大；**硬切**；停留 1.5–4s；红字用 #F50000 |
| **压暗 B-roll 关键词卡** | B-roll 亮度压到 **35–45%**；中文 ≈180px、字距大，英文副标≈86px 细一点；入场 0.4s 模糊→清晰 + 缩小；白色柔光 |
| **章节卡** | 网格底 + 巨幅深灰幽灵字（#151515，字高≈0.6H）+ 荧光绿 #9BF900 标签块（黑粗体，≈76px，块高≈0.105H，中心 (0.49W, 0.33H)）+ 标题 #EDEDED ≈159px（中心 y 0.49H，标题淡入 0.4s 从 35% 到 100%）；总长 1.3–3s |
| **HUD 标签** | 文本 + 背景色：贴左边，x 0–0.12W，起 y 0.03H，每枚高≈0.055H，当前项 #9BF900 黑字，其余灰（#6E6E6E 80%）浅灰字；斜体粗黑体，≈45px |
| **药丸/步骤卡** | 圆角矩形（圆角 18px）+ 文本，颜色 #FB8450 / #8CC2F9；步骤卡由下滑入 0.6s |
| **对比卡 result_pair** | 两条画中画并排：左 x 0.19W 宽 0.27W，右 x 0.515W 宽 0.285W，右卡加 2px 黄虚线 #FCDD1E，上方标签；硬切进出 |
| **大数字卡** | B-roll 亮度 45%（可降饱和）+ 文本：数字字高 ≈0.32–0.36H（≈540px 窄体），中心 y≈0.415H，色 #ECECEC；顶部标题 56px，y 0.15H；**1 帧硬切、不做数字滚动**；停留 2–4s |
| **总结卡** | 三行文本（x 0.2–0.8W，首行 y 0.30H，行距 0.17H）+ 绿色序号圆 #9BF900；每条在说到时出现（动画 0.2s），未出现不显示或 35% 透明 |
| **问题卡打字机** | 文字入场动画选"打字机"，字速≈每 5 帧一字（0.17s/字）；整卡硬切入 |
| **姓名条打字机** | 同上，每字约 2 帧（0.07s） |

### 6.3 网格背景（一次做好，反复用）
- 底色 **#010101**，网格线 **#1A1A1A**、线宽 2px、间距 **72px**（均校准值）。
- 做成 1920×1080 PNG 放在主轨即可。Remotion 工程里可一键导出：`cd <工程目录> && npx remotion still T-GridBackground out/grid_bg.png --frame=0`；或直接用本 Skill 附带的 `~/.claude/skills/combo-style/templates/grid_bg_1920x1080.png`（已用该命令导出）。
- 幽灵大字：同色系 #151515–#1A1A1A，字高 ≈0.6–0.9H，居中。

## 7. 转场
- **默认硬切**（不选转场）。
- **叠化**：仅"换段"时用（如钩子→正文、正文→情绪段），时长 **0.4–0.5s（12–15 帧）**；1–3 分钟片总共 **≤2 次**。
- "压暗再切"（黑场叠化 0.3–0.4s，估计）全片 ≤1 次。
- 不用：旋转、甩镜、故障、火焰、翻页等花哨转场。
- 转场模糊（可选）：模糊 12 → 0，8–15 帧。

## 8. 音效与配乐（原片无音频，以下全部为"推测/估计"）
- **配乐**：轻科技/电子铺底，无人声，音量约 **12–15%（≈−18 ~ −16 dB，估计）**，口播响度以人声为准；章节切换/结尾可淡入淡出 1s。不使用有版权风险的商业曲目（用剪映"商用素材"或自己有授权的音乐）。
- **音效**（位置 = 对应动画出现帧；音量约 20–40%，估计）：
  - 贴字/标签/callout 弹出：短 **pop/啵**；
  - 章节卡、转场、关键词卡硬切：**嗖/whoosh**（短，≤0.3s）；
  - 数字出现：**叮/ding**；
  - 打字机：**滴答/tick**（可选）。
  - 不要每个贴字都配音效：只在"关键词卡、章节卡、大数字、总结点亮"配，约每 8–10s 一个。
- 响度：口播峰值不超过 −3 dB；导出前整体听一遍，音效不盖过人声。

## 9. 导出
- 1080p、30fps、码率"推荐/较高"、H.264、MP4；导出后用手机/电脑各看一遍。
- 导出前跑一遍 comfort-rules.md 的"手查"项与 SKILL.md 的自检清单。

## 10. 每一镜头的最小操作清单（按分镜表执行）
1. 播放头吸附到该镜头首句字幕起点，分割。
2. 换成该镜头的素材/画面（见分镜表"画面"列）；录屏/B-roll 设置运镜关键帧（§4）。
3. PIP：该镜头需要则保留/新增圆形 PIP，不需要则删。
4. 在"关键词开始 +2 帧"处放贴字，设动画时长（§6.1）。
5. 在该处加音效（§8，按需）。
6. 回头检查：这一刀是否落在换句处；该镜头时长是否在 comfort-rules.md §4 范围；无脸段是否 ≤10s。
