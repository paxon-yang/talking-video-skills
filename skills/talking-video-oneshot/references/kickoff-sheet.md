# 开工单（每支片动手前填一份）

骨架借自 Awesome Opus 5.5 Videos 合集里高赞提示词的共同写法（输入 / 方向 / 结构 / 构建 / 坑 / 开工），内容换成我们自己的规矩。规律编号见 `video-asset-prep/references/principles.md` §23–§27。

```
<输入>
- 主题和一句话结论：
- 配音：paxon 的 Fish Audio 文件（没有就先停在这里要）
- 数字人 / 实拍素材：
- 事实文件：屏上出现的每个数字和说法的出处（没有出处的不上屏）

<方向>
- 淡色纸张底；字幕白胶囊 + 头像 + 关键词绿色；所有打字都是打字机动效 + 音效
- 禁用：深蓝底、宋体、紫色霓虹、满屏 3D 贴纸、冲击波圆环、粒子爆炸、RGB 分离、镜头抖动、镜头光晕、网格地板、闪烁背景、弹跳缓动
- 不做 BGM

<结构>
- 三种候选结构（每种两三行），选哪种、为什么
- 挂在逐词时间上：每个镜头写清 时间 / 画面 / 这一刻的作用 / 怎么离场 / 哪个东西带进下一镜（§26）
- 两处设计好的静音放在哪（§25）；一个招牌镜头是什么

<构建>
- Remotion，一切值只由时间算出，随机数固定种子
- 冻结拆解用 FreezeFrame 一套（§23）；字幕和贴字按 §24 停够

<坑>
- 本片最可能翻车的 3 处，每处写成一个数字（例：「冻结第三次超过 2.5 s 会拖」）

<开工>
- 先出 8 张静帧 + 联络表，自查后再整片渲染
- 渲染前跑 `npm run readcheck <timeline.json>`（§24）
- 交付前：跟上一支片比六项，至少四项不同（§27）；换一个没看过制作过程的会话来评
```
