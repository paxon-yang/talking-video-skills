# 口播默认风格与素材采集（证据型口播：博主A × 博主B 路子）

> 2026-10-28 定为口播片的**默认风格**。起因：第五支第一稿整片用自绘 3D 卡片（环绕、展开、卡片从手上升起），用户评价「一群卡片，感觉 low」，要的是「网上的素材、精美一点」，「口播类基本都得这样做」。
> 参数细节不在这里重复：版式看 packaging.md，内容→画面看 visual-mapping.md，节奏看 comfort-rules.md。本文件只规定**画面主体从哪来**。

## 1. 一句话

主播讲道理，**真实素材当证据**。画面主体是录屏、官网和产品界面、新闻和评论截图、成品片段、B-roll；自绘图形只用来做关键词、数字、步骤这类「素材给不了的东西」。

## 2. 硬指标（选型单和自检都要写数值）

| 指标 | 取值 |
|---|---|
| 真实素材镜头占非主播时长 | ≥60% |
| 自绘卡片镜头（关键词卡、药丸、步骤、自画界面）占全片时长 | ≤20% |
| 宣传片式卡片动效（环绕、3D 展开、一镜到底飞镜） | 每片 ≤1 处，≤4 s，只放在开头钩子或结尾兑现 |
| 能截到真东西的地方 | 不许自己画假的。画「假界面」「假聊天」「假进度条」是最后手段，并在选型单里写明为什么截不到 |
| 静态素材 | 全部线性慢推 1→1.08 或平移，不许静止 |
| 素材底 | 用素材本身或主播画面压暗虚化；**不用纯色底、不用黑网格底**（用户铁律，覆盖 packaging.md 里的「深色网格」） |

## 3. 每句话找什么素材

选型单每一行加一列「素材来源」，按下面优先级填，填不出来才降级：

1. **自己做这条片的真实过程**：录屏、终端、渲染进度、任务清单、对话截图。讲 AI 工作流时这是最有说服力的证据，优先用。
2. **被提到的产品本身**：官网首页、产品界面、操作录屏、官方图标（真官方，不用近似图标）。
3. **社会证据**：评论区、私信、新闻标题、榜单和数据页截图（隐去他人头像和昵称）。
4. **成品**：自己往期视频的片段、样片截图墙。
5. **B-roll**：只能用有授权的（Netflix Open Content、用户自己拍的、AI 生成的实景）。
6. 以上都没有 → 关键词卡或大数字（压暗主播画面做底）。

## 4. 怎么拿到素材

| 素材 | 在哪拿 | 注意 |
|---|---|---|
| 网站截图、滚动录屏 | 云端 Playwright（Chromium 已装）对能访问的站点截图、录 `recordVideo`；云端网络白名单访问不到的站点（HeyGen、Fish Audio、剪映、抖音、B 站等国内站和多数 SaaS），经用户 Mac 的 Remote Control 会话用已登录的 Chrome 截图或录屏，再推私有仓库 tmp 分支取回 | 1920×1080 视口、deviceScaleFactor 2；关掉 cookie 弹窗；登录态里的个人信息要裁掉 |
| 产品操作录屏 | 同上；手机端操作请用户录（用户已录过 Fish Audio，一条 30 秒内） | 裁掉状态栏和录屏指示 |
| 制作过程 | 云端直接录：终端渲染日志、Remotion Studio、静帧墙、GitHub 页面 | 不露密钥、内部路径可以露 |
| 评论 / 私信 | 用户截图；没有就请他截 | 打码他人信息 |
| 官方图标 | `@lobehub/icons-static-svg`（npm），没有的去官网取 SVG/PNG | 低清 PNG 只能小尺寸用 |

素材统一放 `public/projects/<片名>/src/`，在选型单里登记文件名、来源网址、截取日期。

## 5. 素材怎么上画面（不许「贴上去就完」）

- **录屏面板**：白底界面放在 packaging.md §5.5 的面板位，每 3–5 s 一次推近或标注（标注框、荧光笔、聚光灯），推近点落在要讲的那个按钮上。
- **截图**：慢推 + 一个动作（高亮一行、圈一个词、放大一个数字），动作卡在说到它的那个字上（−2…+4 帧）。
- **多张同类**（评论、新闻）：拼贴，1.5–2.5 s 一张硬切或叠入，最多 4 张同屏。
- **主播**：证据段缩成圆形 PIP 陪讲（左下或素材对侧），每 15–20 s 回一次大景 3–6 s。
- **精致度**：截图加 12–16 px 圆角和柔和投影；1:1 像素清晰（截图分辨率 ≥ 显示尺寸 ×1.5）；同屏 ≤1 个主标题。

- [ ] 逐镜头标「真实素材 / 自绘」，算出两个占比，写进自检表。
- [ ] 每张截图、录屏能说出来源网址或拍摄人。
- [ ] 没有一处「明明能截真的却自己画了」。
