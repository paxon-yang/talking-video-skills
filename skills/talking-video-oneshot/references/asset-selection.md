# 构思与选素材：拿到需求后的第一步

> 何时读：每条视频开工时，收完需求、写稿之前。
> 为什么放在最前：素材库是自己一条条攒出来的，最大的价值是「这条视频能用上哪些」。先写稿再找画面，稿子会写成没有画面可配的句子，选出来的也总是最近用过的那几块。先盘点素材，稿子才能顺着手里最强的画面去写。

## 1. 输入
- 用户需求（主题、观点、时长、有无数字人）
- 素材库目录：`library/blocks.md`、`styles.md`、`materials.md` 和规律库（格式见 `../../video-asset-prep/references/library-catalog.md`）
- 最近 2–3 支视频的选型单（避免重复）

目录不存在或很久没更新 → 先花 10 分钟按目录格式补齐用得上的条目，再选。不要凭记忆翻源码。

## 2. 四步

### 第 1 步：拆需求
把需求拆成 4–8 个「要让观众看懂的点」，每个点标内容类型（钩子、对比、流程、关键数字……，词表见目录第 3 节）和想要的情绪。这时还不写句子。

### 第 2 步：定风格
从风格库挑 1 套主风格（必要时 1 套辅助，例如主播段暖暗、讲解段纸张），写理由：
- 和主题气质对不对（工具 / 教程偏纸张，观点 / 故事偏实景 + 数字人）
- 和最近几支要不要区分
- 用户的禁忌（见 forbidden.md 和风格条目的「禁忌」）

### 第 3 步：逐点配素材
每个点在积木库里按「适合表达」+ 情绪 + 主播关系去匹配，给 **首选 + 备选**，写一句为什么。同时查：
- **规律约束**：规律库里有没有限制（身后大字 ≤3 次、冲击镜头 ≤1 次、连续无脸 ≤10 s……）
- **新鲜度**：首选在最近两支里用过 → 换备选，或者换个用法（参数、配色、和主播的关系）
- **新学的素材**：materials.md 里最近「已沉淀」的条目优先找机会用上，这是学习线变成成片的地方
- **缺口**：没有合适积木 → 三选一写清楚：用现有积木组合 / 现做新积木（估时）/ 降级（fallback-ladder.md）

### 第 4 步：反推结构
按配好的素材排出节奏：最强的画面放钩子和反转（60–75% 处），同类积木不相邻，主播回归频率符合 visual-mapping.md §2.3。到这一步再去写稿，句子跟着画面写。

## 3. 产出：选型单 `selection.md`

```markdown
# 选型单：<视频题目>
- 主风格：S-01 淡色纸张（理由）；辅助：S-02 暖暗书房（只用于主播大景）
- 时长 / 数字人：70 s / 有，小窗为主

| # | 要讲的点 | 类型 · 情绪 | 首选积木 | 备选 | 理由 / 约束 |
|---|---|---|---|---|---|
| 1 | 开场钩子 | 钩子 · 抓人 | B-031 输入框放大打字 | B-002 身后大字 | 上支开头用了身后大字，这次换 |
| 2 | 以前 vs 现在 | 对比 · 惊讶 | B-014 双药丸对比 | — | |
| 3 | 四个步骤 | 流程 · 平稳 | B-008 步骤线 + 角标 | B-023 卡片环绕 | 规律 §7：步骤 ≤4 |
| … | | | | | |

- 本片用上的新素材：M-2026-10-21-a 拆出的「光带扫过」→ 用在第 5 点
- 缺口：第 6 点「趋势」没有积木 → 降级：外部图表 PNG + 慢推（visual-mapping §1）
- 规律检查：身后大字 2 次 ✓；冲击镜头 1 次 ✓；最长无脸段 8 s ✓
- 需要的外部素材：Gemini 背景 1 张、Pexels 实景 2 段（清单见 gemini-asset-prompts.md）
```

选型单是镜头表（S6）的上游：镜头表里每个镜头用的组件，都应该能在选型单里找到出处。

## 4. 要不要给用户看
- 默认**不停下来问**，选型单随稿子一起交，用户看稿时顺便看到用了什么。
- 例外：主风格换成用户没见过的方案，或者某个点需要现做新积木（会多花时间）时，一次性问清楚，给选项。

## 5. 交付后回写
- 用到的积木在目录里补「用过」。
- 用户否掉的画面写进那块积木的「不适合」。
- 这次现做的新积木按入库闸登记（library-catalog.md 第 4 节）。
