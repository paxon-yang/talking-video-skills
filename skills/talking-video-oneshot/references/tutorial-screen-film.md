# 干货实操片（教程 / 全流程拆解）怎么做

> 来源：第十支「AI 全自动剪视频」，2026-11-18 到 11-20 一共改了 5 版，用户逐条反馈后定下来的做法。
> 什么时候读：选题是「教程」「我是怎么做的」「全流程拆解」这类干货分享片时，开工前先读这一篇。证据型口播的通用规矩照旧，这里只写这类片子多出来的规矩和反例。

## 1. 片型：主体是实操，不是主播

- **画面主体是真操作**：真网站录屏、真手机界面、真产品流程。用户的原话是：「这期其实是干货分享，你得有大量实操的部分」。
- **数字人只出现在开头（≤10 s）和结尾**。中段不放主播点头、讲解的镜头，用户说「没必要那么多数字人」。中段要压暗做底时，可以用主播画面虚化。
- **不许用静态截图当画面**。窗口里贴一张网页截图、手机里贴一张图，都会被评为「贴图、没有动态感」。网页要真录，手机要做活界面（打字、发送、消息气泡逐条出来，视频气泡能播）。
- 时长可以比观点片长（这一支 2:51），但每一步讲完就走，不重复。

## 2. 网页录屏：逐帧录真网站，后期加工

- 用无头浏览器逐帧截图，录真网站的滚动、悬停、点击、打字，同时记下光标轨迹和点击时刻。录完逐帧合成，画面是逐帧的，不会掉帧。
- 后期在合成里画光标和点击波纹，可以多标签页切换。每个窗口在讲解点推近一次就够，别来回晃。
- 点一下会报错的按钮（比如没填内容就点「生成」），改成悬停高亮，别把报错录进去。
- 别人的账号、头像、水印一律裁掉或打码，不点名。
- 窗口避开常驻的角标（比如右上角的账本）。

## 3. 章节过渡页：进度线 + 配音暂停

- 每一步开头放一张过渡页：上面写「第 N 步 + 大标题」，下面一条进度线，有几步就几个节点，走到哪一步，哪个节点亮。
- **过渡页期间配音暂停**，只放一声音效（章节卡那种低沉冲击）。过渡页播完，配音再接着往下放。
- 停留约 2.2 s（进场 16 帧、停 34 帧、出场 16 帧）。一闪而过不行，靠时间线叠在内容上「盖一下」也不行。
- 风格先出几种样片让用户选（这次出了 5 种）。用户选的是「缩成节点穿梭」：上一段画面缩成小缩略图落到当前节点上，沿线滑到下一节点，下一段从那里长出来铺满全屏。
- 实现思路：把「按配音时间排好的整片内容」当成一个组件，在章节点把它切成几段，段和段之间插入间隙。间隙里的过渡页，两端用上一段最后一帧和下一段第一帧的定格画面。顺带一个好处：配音里要删掉的句子，也能用这个办法在片内直接跳过，不用渲完再剪。

## 4. 情绪转折的地方要软着陆

- **主播的走心、坦白句**（比如「我在镜头前说话紧张」）不能硬切进来。前面让配音停 1 s，做柔和转场：上一镜推近、虚化、压暗，一道暖光扫过，下一镜由虚到实，轻微拉回。
- **从屏幕画面进到结尾主播**：先把屏幕画面压暗，主播画面从中间一张金边圆角卡片放大，约 0.7 s 铺满全屏，配一声轻的「嗖」。

## 5. 想表达什么 → 怎么演（这一支被认可的做法）

| 想表达 | 做法 | 反例（被否过） |
|---|---|---|
| 一个关键数字（20万+、40 分钟、4 刀） | 数字滚轮：每一位滚动，高位先停，带运动模糊，最后收敛清晰；落定时配一声冲击 | 数字直接出现 |
| 并列的几个关键词（质量 / 稳定性 / 效率 / 成本） | 金边玻璃徽章跟着配音逐个翻起，每个带一个线条图标，点亮时有金色冲击环，最后一条金线把它们串起来 | 只放几个金色大字，「目前就放字有点丑」 |
| 提到在用的软件 / 平台 | 官方 App 图标展台：图标落到镜面台上，带倒影和扫光；「我在用」的那个更大，带金色光环；「平替」的小一号，挂标签 | 文字列出软件名；自己画的假 logo |
| 一个定性词（「你只是一个裁判」） | 金色大字从放大、虚化的状态砸下来，带冲击环和轻微震动 | 小字带过 |
| 很多张图在批量生成 / 渲染 | 蜂群光标：一群标着「AI 01、AI 02…」的彩色光标各自飞到格子上，落点一闪，那一格就渲出来 | 格子自己一个个亮起来 |
| 出封面、写文案、归档 | 手机里是抖音发布预览：竖封面，文案逐字打出来。笔记本里先放横封面，再切到云盘页面，文件逐个上传、打勾 | 平铺三张卡片（竖封面、横封面、文案卡），被评「很 low」 |
| AI 自己去某个网站干活 | 先放真官网录屏，再接一个生成过程面板：画面扫描着揭开，步骤逐个点亮，带计时 | 终端滚日志 |
| 讲 skill / 动效库 | 塔罗牌式翻出关键词，再接真页面录屏，两样都要 | 只有塔罗牌，或只有页面 |
| 用手机下指令 | 立体手机活界面：在输入框打字，发送，回复逐字流出，可以带视频或图片气泡 | 手机里贴一张聊天截图 |

## 6. 这类片子不要的

- **终端 / 命令行画面**：只在极少数非用不可的地方用，默认一个都不放，换成更生动的表现。
- 静态截图贴图、卡片「出现 → 停住 → 滑走」、过渡页一闪而过、灰色大字、划线划掉、橙色胶囊（通用禁忌照旧）。

## 7. 音效

- 只从音效库按标签挑，库里实在没有才自己合成。
- **少而准，只放在画面真有动作的地方**：录屏里的点击、logo 落台、截图快门、数字落定、大字砸下、上传完成、渲染完成。
- 过渡页只放一声，不要嗖嗖声一路响，不要键盘声，也不要 BGM。用户批评过：「全局配的音效都很奇怪」。

## 8. 流程上的坑

- 过渡风格、大改动先出样片或静帧让用户选，再渲全片：整片渲一次要 25–30 分钟。
- 渲之前清掉旧的打包缓存，否则磁盘会在渲到一半时写满，渲染失败。
- 配音里个别字发音有问题，可以从同一条配音别处剪同一个字的发音拼进去，前后各加 12 ms 交叉淡化，不用花钱重新生成。
