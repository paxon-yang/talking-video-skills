# 开头手法库、文案规则、结尾 CTA

## 1. 开头硬规则

1. **3 秒内**必须出现钩子，并有**第一次画面变化**（贴字弹出或硬切）。
2. 不寒暄、不自我介绍、不放 Logo。问候最多 1s，可晚到 30s 后。
3. 开头 20–30s 是全片最密的一段：≥5 刀、2–3 个贴字。
4. 钩子后紧跟"定义 + 预告"（我要讲什么、你会得到什么）。
5. 悬念类钩子要兑现，兑现点放在结尾并回扣开头。

## 2. 开头手法库（每种 2–3 个填空模板）

选法：教程型默认 ①②③④；观点型 ①⑥；数据型 ⑤⑦。`{}` 里是要填的内容。
按观众的「想」选手法：先定这条片要勾起哪个「想」，再查 audience-triggers.md §3 的对照表。

### ① 问句 + 关键词红
- 「{时代/变化}，{目标人群}真的有{机会}吗？」
- 「开完{场景}，你还在{旧做法}吗？」
- 「{人群}最怕的{事}，其实有{解法}？」
前 3 秒画面：主播居中，标题逐词出现，{人群}/{旧做法}标红；或压暗 B-roll + 整句宋体标题。组件：keyword_card(on_broll) 或 host_tag + head_flank。

### ② 夹头词 + 一句承诺
- 「你敢信？{A}就能{B}」
- 「{工具}出{能力}了」
- 「只要{一个动作}，{成品}就{变化}」（必须有真实实测支撑，不夸大）
画面：主播摊手，左右大字夹头（左 {A}，右 {B}），第 4s 才第一次硬切。组件：host_tag + 两个 head_flank。

### ③ 以前 / 现在反差
- 「以前做{事}你得{门槛1}、{门槛2}、{门槛3}，现在只需要{一个动作}」
- 「{旧成本}曾经是{N}，现在是{M}」
画面：双药丸 + 步骤逐行；{门槛}用头部浮动小词，{动作}用两侧巨字。组件：compare(pills_vs)。

### ④ 成品预告 + 悬念
- 「先来{N}秒直观感受，看到结尾有惊喜」
- 「教你个{小招}，做出这样的{成品}」
画面：成品快进 5–8s，再回主播。（需有成品素材；没有就别用。）

### ⑤ 最高级 / 反常识数字
- 「今天说说最近{最高级}的{事件}。你还记得{A}和{B}吗？这笔是那两个的总和」
- 「{数字}，这是{对象}一年的{指标}，比{参照物}还多」
画面：主播直接开口，约 7s 硬切标题卡，随后进图表/大数字。

### ⑥ 反转
- 「你手里免费的{X}，其实一直藏着{Y}，大多数人不知道」
- 「{大家都在做的事}，其实{反面}」
画面：界面推近 + 箭头（callout）。

### ⑦ 新闻冷开场
- 「{时间}，{权威机构}不是判{人物}的{政策}违法了吗？那{之前的动作}都白忙了吗？」
- 「{时间}，{事件}发生了，{一个让人意外的细节}」
画面：新闻 B-roll 快切（1.5–2.5s/张），字幕直接陈述。

### ⑧ 极端设定（1–3 分钟慎用，压到 ≤8s）
- 「如果有一天{极端设定}，你该怎么办？」
画面：电影感 B-roll 压暗 + 居中白字。

### ⑨ 亲历（博主B ex08 新增，数据/事件型备选）
- 「我前一阵子去了{地点}。你一下飞机就感觉{感官反差}。{3–4 句快切奇观，每句一个镜头}。注意，我说的{奇观}，不是{普通理解}，而是{反常识细节}」
- 转折模板（约 1:10 处，1–3 分钟版放在 25–40% 处）：「{地点}怎么从{弱势}变成{强势}？你可能想当然觉得是靠{常识答案}，其实{常识答案}很少」
画面：风景空镜 + 字幕叙述 → 2s 主播一句亲历 → B-roll 快切；无片头、无 Logo。需要用户真有亲历/素材。

## 3. 文案写法规则（可执行）

1. **语速** 5.0–5.5 字/秒（含停顿实际 4.5–5）；数字人 TTS 倍速按 1.0–1.1 调，以实测为准；数据型上限 6.0；类比/情绪段可降到 4.3–4.6 做"消化时间"。
2. **口播句长** ≤20 字，一句一个意思，对应字幕 1–2 行。
3. **字幕行** 8–10 字/行，最长 14 字（不含标点），约 1.7–2.3s/行；句中停顿用空格，句末保留"？"。
4. **句首衔接词**：那 / OK / 其实 / 但是 / 所以 / 你看；每 20–30s 一个问句。
5. **三连排比**：同构三例，观众只换名词；三例之后立即用三个形容词抽象归纳。
6. **每个功能/板块固定三拍**：痛点一句 → 界面或图（7–10s）→ 价值一句。
7. **每个关键数字单独成句**，并给参照物。
8. **新概念**每 10s ≤1 个，每句 ≤1 个新名词（估计）。
9. **自曝不足**放在总结之后、呼吁之前，主播全屏说。
10. **CTA 只在结尾出现一次**（1–3 分钟片不在开头 30s 插 CTA）。
11. **同一意象**口播说一次，画面至少 2 个镜头。
12. **数据不编造**：示例数字必须标"示例"；真实数字写来源。

## 4. 口播稿标记写法（可直接粘进数字人工具；`/`、`【】` 来自流程约定，`//`、`〔〕` 为本 Skill 自定约定）

| 标记 | 含义 | 规则 |
|---|---|---|
| `/` | 停顿（约 0.3–0.5s） | 句中语义停顿、数字前后；每句 ≤2 个 |
| `//` | 长停顿（约 0.8s） | 段落转折、钩子后；全片 ≤5 个 |
| `【】` | 重读 | 每句 ≤1 处，对应关键词；同时是 ScriptJSON `marks` |
| `〔〕` | 贴字（level 2） | 可选，仅出分镜时用，不粘进数字人工具 |
| 句末 `？` | 升调 | 问句保留 |

示例（目标语速 5.0 字/秒）：
`你敢信？/ 开会十分钟，// 整理纪要要【四十分钟】？`（示例句式，换成自己的内容）
注意：数字人工具的粘贴版要**去掉 `〔〕` 和 `//` 之外不被支持的标记**；不确定工具是否识别 `/`，需按工具确认（见 digital-human.md）。

## 5. 结尾与 CTA

结构（6–15s）：
1. **一句复述**（总结卡逐条点亮，3–4s）。
2. **（可选）坦白不足一句**，主播全屏。
3. **一句提问**（把话题还给观众，主播 + 夹头词，2–3s）。
4. **一句行动**（关注/评论，一次，不超过 1 句）。
5. 回扣开头钩子的梗或悬念（兑现）。

填空模板：
- 「记住这{N}步：{步1}、{步2}、{步3}。」
- 「你最想让AI替你做{哪件事}？评论区告诉我。」
- 「{开头的疑问}，现在你有答案了。」
- 数据/观点型金句卡：一句 ≤20 字的价值观句，深色底，关键词染黄。

**不做**：固定片尾口播、吉祥物升起、账号名片尾卡、"谢谢观看"卡（见 forbidden.md）。
