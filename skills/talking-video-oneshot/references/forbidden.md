# 禁区：不能复制的标志性元素与替换建议

> 原则：学"怎么做"，不搬"做了什么"。可迁移的是规律与版式；不可迁移的是原博主的身份标识、口头禅、形象、产品内容。
> 本 Skill 不引用原博主原句；做稿时也不要凭印象写入"听起来像他们"的口头禅或标题套话。

## 1. 一律替换

| 元素 | 类别 | 替换建议 |
|---|---|---|
| 账号名片尾卡、吉祥物升起、固定片尾口播与手势、"谢谢观看"卡 | 身份标识 | 自己的账号名与形象；或干脆不做片尾卡，用主播一句行动收尾（ClosingCard 在 Remotion 里也未实现） |
| 产品名、Logo、相关概念词、吉祥物 | 品牌 | 换成用户自己的品牌/自己的选题产品；Logo 由用户提供 |
| 主播形象：服装与发型、紫色霓虹房间、粉色闪电灯牌、灰卫衣、条纹衬衫、书柜演播室、沙发霓虹背景 | 人设 | 用户自己的数字人；背景用自己的暗色单色/场景（见 digital-human.md） |
| 签名口号、固定问候、固定开场白、"{账号}的…"式固定标题卡、固定的过场提示句、借流行语起的标题 | 口号 | **句式结构可以参考**（填空模板），**措辞必须换掉**；不使用原博主的任何一句话 |
| 博主B 的口头禅与感叹语、红字金句片尾卡、招牌式转折句 | 人设梗 | 换成自己的口语衔接词（那/OK/其实/但是/所以/你看）；金句卡的位置可用，文案自己写 |
| 3D 卡通角色（吉祥物、固定出镜的卡通人物、花衬衫女孩等） | 形象 | 若要用，重新生成一套**自己的**角色并全片统一；默认不做（成本高、可选） |
| 国旗纹理章节角标、火焰转场、爆炸素材叠化 | 标志性装饰 | 不复刻；章节用荧光绿 HUD 即可 |
| 口播广告段 | 内容 | 不做 |
| Agent 生成的被测特效成片（被测产品的产出，不是包装） | 内容 | 不复刻 |
| 综艺化元素：VHS 快进、"N YEARS LATER"恶搞卡、梗图/影视反应、漫画拟声爆炸、副机位实拍 REC 框 | 人设/综艺 | 不做；确需活跃气氛用 punch-in 或夹头词代替 |
| 原片的具体素材：新闻截图、人物抠像、数据（金额/比例/时间）、案例、结论 | 内容 | 全部换成用户自己的选题和自己能提供的素材；数据必须有出处，示例数据必须标"示例" |

## 2. 可以沿用的视觉母题（主色换成自己的）

黑底网格、荧光绿标签、圆角药丸、抠像白边、圆形 PIP、关键词卡、章节卡、字幕条、HUD 栈。
- 颜色：保留"暗底 + ≤3 个强调色"的结构；荧光绿 #9BF900 / 黄 #F8D800 / 橙 #F25A1A 是博主A的配色，**如果要和原博主拉开，整体换成自己的 3 个强调色**（Remotion 里主要在 `tokens.ts`，只读；手工路径随意）。
- 字体：用可商用字体；毛笔体务必确认授权。
- 素材：B-roll、配乐、字体、Logo 自行确认版权。

## 3. 自检清单（交付前扫一遍）

- [ ] 口播稿里没有任何一句话是原博主的原句，也没有他们的口头禅/问候/片尾套话。
- [ ] 标题与封面文案没用"{账号}的…"这类固定标题形式。
- [ ] 数字人形象、服装、背景不是原博主的。
- [ ] 画面里没有国旗纹理角标、火焰转场、账号片尾卡、吉祥物。
- [ ] 所有产品名、Logo、数据都是用户自己的或有出处。
- [ ] 视频、帧文件只在本地使用，不二次发布原片素材。
