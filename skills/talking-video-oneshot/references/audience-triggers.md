# 观众七个「想」：选题和钩子的流量触发点

> 来源：一条抖音图文转发的推文（「流量大师」给出的容易爆发流量的 7 点），2026-10-23 入库。原文只有 7 个短语，下面的解释、手法和对照都是本 skill 自己推出来的，没有实测数据，置信度标「估计」。
> 何时读：选题 5 问（thinking.md §2）之后、选钩子（hooks-and-copy.md §2）之前。

## 1. 核心意思

七条说的是同一件事：**让观众有话要说、有事要做**。点赞靠认同，爆发靠评论、转发、看完、二刷，这几样都要观众「参与」。所以选题时不只问「观众能学到什么」，还要问「观众看完想干什么」。

七条按观众的动作分三组：

| 组 | 观众想… | 带来什么 |
|---|---|---|
| 想说（评论） | ① 纠正你　⑤ 给你支招　⑦ 证明自己 | 评论区吵起来、长评论 |
| 想看（完播） | ② 看结果　③ 看翻车　④ 辨真伪 | 停留、看完、二刷找细节 |
| 想代入（转发） | ⑥ 带入自己 | 转发给朋友、@人、收藏 |

## 2. 七条逐个拆

每条给：观众心理 → 在 AI / Claude 题材里怎么落 → 钩子填空 → 画面建议 → 风险。

### ① 想纠正你
- 心理：看到「不对」比看到「对」更想开口。
- 怎么落：给一个**有争议但站得住**的判断，或者一个故意不全的排序（「我心里 Claude 最强的 3 个用法」，第 4 名留给评论区补）。
- 钩子：「我说个可能被骂的观点：{反常识判断}」「{大家公认的做法}，我觉得是错的」
- 画面：主播大景说判断 + 夹头词；判断句做关键词卡，争议词标绿。
- 风险：**不留真错误**。知识号靠专业感，故意写错一次会被截图挂；留的是「可讨论」，不是「可挑错」。

### ② 想看结果
- 心理：过程可以快进，结果必须看到。
- 怎么落：开头先放成品（AI 做出来的视频、跑完的数据、前后对比），再讲怎么做的。
- 钩子：用 hooks-and-copy ④ 成品预告；「{N} 分钟，{工具}帮我做出了这个」
- 画面：成品快进 5–8 s → 回主播；结尾再放一次完整结果回扣。
- 风险：成品必须真的好，开头放平庸成品比不放更伤。

### ③ 想看翻车
- 心理：失败比成功好看，也更可信。
- 怎么落：把自己真实踩过的坑做成片段：AI 写错、渲染卡死、积分烧光、被拒稿。
- 钩子：「我让 AI 做{事}，结果翻车了」「花了{钱/时间}，换来一个{离谱结果}」
- 画面：翻车画面原样放（截图 / 录屏），配一个停顿和音效，再讲原因和解法。放在 60–75% 的反转位也合适。
- 风险：翻车之后一定要给「为什么 + 怎么避」，否则只是吐槽，没有收藏价值。

### ④ 想辨真伪
- 心理：观众想当裁判，自己判断是真是假。
- 怎么落：热门说法 / 宣传 / 截图拿来实测验证；或者两个结果让观众猜哪个是 AI 做的。
- 钩子：「网上都在说{说法}，我实测了一下」「这两个，哪个是 AI 做的？」
- 画面：A / B 并排（compare 双卡），先不揭晓，停 1–2 s 再翻牌；揭晓放在后半段。
- 风险：揭晓前别拖太久；数据要真，来源写清（hooks-and-copy §3 第 12 条）。

### ⑤ 想给你支招
- 心理：观众觉得自己有更好的办法，想教你。
- 怎么落：真诚地抛出一个自己还没解决的问题，或者摆出现在的做法问「还有更快的吗」。
- 钩子：「这一步我到现在还没找到好办法」「我现在是这么做的，你们有更省事的吗？」
- 画面：放在结尾 CTA 处（hooks-and-copy §5 第 3 步「一句提问」），主播全屏真诚说，不加花哨动效。
- 风险：问题要具体到观众能答，「大家觉得呢」没人回。

### ⑥ 想带入自己
- 心理：「这说的就是我」「这个我也能用」。
- 怎么落：把功能讲成具体人物的具体场景（上班族写周报、学生改论文、老板看报表），或者用第二人称「你」开头。
- 钩子：hooks-and-copy ① 问句（「{人群}最怕的{事}」）、③ 以前/现在；「如果你也{场景}，这条视频你一定要看完」
- 画面：场景实景 / B-roll + 人群词标绿；三连排比用三类人各一个例子，让不同观众都能对上号。
- 风险：人群写太宽等于没写，一条片子主打 1–2 类人。

### ⑦ 想证明自己
- 心理：观众想显示「我懂」「我做到了」「我早就知道」。
- 怎么落：出一道小题、一个小测试、一个门槛（「能看懂这张图的不超过 10%」「你用 AI 做过最离谱的事是什么」）。
- 钩子：「这个问题，{大多数人}答错了」「你能在 3 秒内看出{X}吗？」
- 画面：题目卡停留 2–3 s（给观众答题时间），答案后置；结尾邀请评论区晒结果。
- 风险：别做成智商测试式标题党；题目和主题必须相关。

## 3. 怎么用进流程

1. **选题 5 问之后加一问**：「这条片能勾起哪 1–2 个『想』？」写进选型单。一个都对不上 → 换角度；对上 3 个以上 → 选最强的 2 个，别全用。
2. **一条片子的推荐组合**（估计）：一个「想看」做钩子留人，一个「想说」做结尾留评论。例如 ② 看结果开头 + ⑤ 支招收尾；④ 辨真伪开头 + ⑦ 证明自己收尾。
3. **对应已有开头手法**：

| 七个想 | 首选手法（hooks-and-copy §2） | 首选画面积木 |
|---|---|---|
| ① 纠正你 | ⑥ 反转 | 主播大景 + 夹头词、关键词卡 |
| ② 看结果 | ④ 成品预告 | 成品快进、前后对比 |
| ③ 看翻车 | ⑥ 反转、⑨ 亲历 | 录屏原样 + 停顿音效 |
| ④ 辨真伪 | ⑤ 反常识数字、⑦ 新闻冷开场 | compare 双卡翻牌 |
| ⑤ 给你支招 | （结尾用，不做钩子） | 主播全屏 |
| ⑥ 带入自己 | ① 问句、③ 以前/现在 | 实景 B-roll + 人群词标绿 |
| ⑦ 证明自己 | ① 问句 | 题目卡停留 + 后置答案 |

4. **结尾 CTA 的提问**（hooks-and-copy §5 第 3 步）优先写成 ⑤ 或 ⑦ 的形式，比「你怎么看」更容易有人答。
