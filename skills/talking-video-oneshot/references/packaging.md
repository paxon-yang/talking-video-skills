# 包装规范：字幕、色值、字体、版式（数值版）

> 画布 1920×1080，30fps。坐标为画布比例（x 相对宽 W，y 相对高 H）。
> **事实来源优先级**：`<工程目录>/src/tokens.ts` 与组件（已按证据帧校准）＞ style-report.md。两者不同处本文件一律取 Remotion 校准值，并在"校准"列标出原设计值。
> "实测"= 从原片取样；"估计"= 目测/推算；"校准"= 第 1/3 步按证据帧修正过。

## 4. 版式网格与安全区

- 安全边距 5%（54px），角标可贴 1–3%。
- 大字走中轴 x=0.5 或三分线 x=0.333 / 0.667；主标题字高 0.08–0.14H（86–151px），y 集中在上 2/3。
- 一屏最多 **1 个主标题 + 3–4 要素**；文字面积中位 1–2%。
- 禁入区：字幕带 y 0.86–0.93；PIP 区 x 0.01–0.15、y 0.78–0.92；HUD 区 x 0–0.29、y 0.03–0.17。
- 底只用两种：素材本身，或压暗的 B-roll / 主播画面（亮度保留 20–45%）。**不用纯色底、不用黑网格底**（用户铁律；下文 grid 变体、章节卡网格底一律换成压暗主播画面）。切点不刻意匹配亮度。

## 6. 两种主题的差异

| 维度 | 博主A主题（`qiuzhi_dark`，默认） | 博主B 主题（`xiaolin_data`） |
|---|---|---|
| 字幕 | 黑圆角底，46px，y 0.905 | 白字黑描边，56px，y 0.885 |
| 版式 | 大字走中轴/三分线，边距中位 12% | 贴边角标、左下章节签，边距中位 6% |
| 色彩 | 暗紫霓虹背景 + 荧光绿/黄标签 | 红/橙为主，亮度更均衡；数据图绿/黄/红/紫 |
| 贴字入场 | 快（中位 0.33s，约 30% 硬切） | 慢（0.67s，淡入/模糊为主） |
| PIP | 左下圆形，紫环 4px | 圆形无环（可选 br_rect 竖卡） |
| 运镜 | 录屏推拉 ease-in-out ×1.12/0.9s；切后"冲入" | 静态素材线性慢推 ±5–10%；慢推跨切延续 |
| 软转场 | 0–1.9 次/分 | 1.4–3.1 次/分 |
| 剪辑密度 | 6.8–20 刀/分（中位约 16） | 25–30 刀/分 |

**当前 Remotion 的主题实现**：`timeline.meta.theme` 仅是标签，**渲染器不读取**。博主B 风格只能靠逐条设置 `subtitles[].style:"stroke"`、选 `br_rect` PIP、用线性慢推、`big_number.gold_card` 等"零件"拼出来；PIP 紫环没有按主题关闭。默认请用博主A主题，借博主B 的零件（见 style-report 取舍）。
